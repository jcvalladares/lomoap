### Title: Origami Risk Launches New Cloud-Native Core Solution for MGAs

#### Summary:
Origami Risk, the industry-leading risk, safety, and insurance software as a service (SaaS) firm, has announced the launch of a new cloud-native core solution specifically designed for managing general agencies (MGAs). This solution aims to significantly accelerate the implementation of core functionality and policy rollouts, making it accessible and affordable for smaller and startup MGA clients.

The new solution offers a streamlined approach to requirements gathering, predefined sprint plans, standardized resourcing and staffing plans, and a flexible pricing model that allows clients to start with essential functionality and grow over time. Additionally, it includes comprehensive user guides, out-of-the-box functionalities such as preconfigured transaction forms, integration with external raters, and a standard database.

This innovative cloud-native core solution is built on Origami's extensive insurance solutions for MGAs available on a highly configurable, fully integrated platform, providing seamless integration and efficient management of risk across various sectors including P&C Insurance, construction, government, healthcare, manufacturing, transportation, and resource management.
