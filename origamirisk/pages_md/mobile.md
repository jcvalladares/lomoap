# Mobile App for On-Site Risk and Safety Data

## Summary
Origami Mobile is a mobile application designed to enhance operations with an innovative platform built for speed, scalability, and security. It provides seamless integration with data sources, expert system configuration and guidance, intuitive app for on-the-go reporting, customizable dashboards, purpose-built solutions for risk, safety, and insurance, and various resources including case studies, news, events, and about us.

## Key Features
- **Real-time Data Collection**: Capture field data instantly and accurately.
- **Secure Sign-in**: Easy access with credentials, shared codes, or face/fingerprint authentication.
- **Offline Access**: Complete tasks without internet connectivity.
- **Smart Navigation**: Identify key information quickly.
- **Automatic Timeout**: Prevent unauthorized access when devices are left unattended.
- **Automation Tools**: Boost efficiency with automated workflows.
- **Role-Based Permissions**: Configure access based on multiple characteristics.
- **Enhanced Reporting**: Annotated media and visual documentation from the field.
- **Voice-to-Text**: Easily input data with hands-free reporting.
- **Admin Portal**: Manage users, settings, and platform controls.
- **API Access**: Connect systems seamlessly with REST API and web services.
- **Communication Center**: Centralize email, text, and chat.
- **Document Management**: Secure cloud-based tools for document storage and generation.
- **Security Sharing**: Regularly refreshed, structured data securely using Databricks Delta Sharing.
