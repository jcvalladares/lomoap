# New Core System Implementation Success Rate Study

## Introduction
This study examines the implementation timelines and outcomes of six leading P&C insurance core system vendors, using publicly available go-live project data. It provides valuable benchmarks for insurers to make informed decisions in their vendor selection process. The findings reveal that prioritizing partners that can deliver rapid speed to value can accelerate digital transformation journeys and realize the benefits of modern P&C insurance technology.

## Key Findings
1. **Implementation Timelines**: The variability in implementation durations among top P&C providers highlights the importance of selecting partners with strong delivery capabilities.
2. **Project Scope**: Singular policy or claims implementations tend to be faster than full suite implementations, indicating the need for flexibility in project management.
3. **Geography**: Geographic scope does not significantly influence implementation timelines, suggesting that the effectiveness of the platform depends on the company's overall strategy rather than its location.
4. **New vs. Expansion Projects**: New implementations are generally more efficient compared to expansion projects involving existing vendors, indicating the need for proactive planning and resource allocation.
