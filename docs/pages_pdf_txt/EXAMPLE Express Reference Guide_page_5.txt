EXAMPLE Express ®and Other Systems
Through EXAMPLE Server ®, data collected using EXAMPLE Express ®can be passed to downstream systems. In
addition, EXAMPLE Express ®itself can be integrated with other systems using custom post actions and custom
content pages.
For information about EXAMPLE Server ®and options for integration, see the Guide to EXAMPLE Server® . For
information about custom post actions and content pages, see OnDemand Framework andCustomizing EXAMPLE
Express® .
