Search Page
The Search page provides the ability to search for clients, policies, and quotes using a variety of search options.
When searching for a policy or quote, the search results will include policies and quotes from all entities
where the user has the ViewQuotes privilege. When searching for a client, the search results will include all
clients from all entities where the user has the ViewClients privilege and where the client has a quote for an
entity to which the user belongs.
