Changing Browser Languages
Localizing EXAMPLE Express ®skins requires that you change your browser language settings. You can change your
browser language settings by:
•Changing the language in your Web browser. For more information, see Changing Your Browser Language in a
Web Browser .
•Modifying the value of the appSettings configuration setting in the Express\web.config file. For more information,
seeChanging Your Browser Language Using a Configuration Setting .
Using a configuration setting to modify your browser language settings is recommended when changing
the browser language on multiple machines at once.
