Task Management
The Task Management page is intended for users who must be able to view and manage task workloads. This page
displays all tasks in all queues the user has permission to work with. On this page, users can filter tasks by queue, due
date, assignee, status, category, or the date created. Users can then use a shortcut to reassign tasks, or open task
