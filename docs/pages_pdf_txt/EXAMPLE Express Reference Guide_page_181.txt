Integer setting (0,1,2,3) used to log the XML content of each request to the EXAMPLE Express ®system. Debug is
turned on if the value of the setting is greater than 0. Each request is sent to the debugContent.xml file located in the
EXAMPLE Express ®directory or to the directory indicated by the DebugOutputDir configuration setting. As a result,
Duck Creek Technologies, Inc. recommends setting this value to 0 on a runtime system.
