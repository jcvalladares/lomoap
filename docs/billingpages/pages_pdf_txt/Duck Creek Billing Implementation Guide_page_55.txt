Configuring Commission Options
Commission rate and eligibility are determined in the policy system and transmitted to Duck Creek Billing™ on the
policy term premium record. Records are written to database tables based on the commission scheme specified in the
Policy Plan Setup option. The CommissionStatementSchedule database table maps an agent to the statement
schedule and produces statements based on the data in the table.
The <BillCommission.buildCommissionStatementRq> request populates the following two tables:
•DC_BIL_DirectBillCommissionStatementSummary — Contains information needed by a check-writing
interface.
•DC_BIL_DirectBillCommissionStatementDetails — Contains details for statement make-up to generate
printable statement.
Most data in these tables is stored in an XML column.
Commission statement requests should be initiated serially from a single source and processed by a single
server to avoid possible race conditions between multiple threads and/or servers when writing to the
disbursements file.
Commission processing uses two requests:
•The <BillCommission.buildCommissionStatementRq> request uses the agencyId, statementDate, and
printDirectory attributes.
•The <BillCommission.printCommissionStatementRq> request uses the statementId and printDirectory parameters
to generate printable statements. This request initiates a report using SQL Server 2005 Reporting Services to
produce statements.
Reports are output as PDF files to the directory specified in the printDirectory attribute. If the print directory is not
passed in as an attribute, the DirectBillCommissionStatementsFolderRootPath setting in the Server.Config file is used.
The statement file name will be DirectBillCommissionStatement_Agency_[Agency]_[StatementDate]_[StatementId].pdf.
Customers are responsible for printing and sending the statements, or maintaining the files.
