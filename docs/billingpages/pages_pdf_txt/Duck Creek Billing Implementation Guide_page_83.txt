The Disbursement Interface Service processes all Duck Creek Billing™ disbursements whether they originate from
within Duck Creek Billing™ or are paid using a system that is external to Duck Creek Billing™. External disbursements
are subject to the same authorization rules as internal disbursements.
A disbursement cannot be requested and authorized by the same Duck Creek Billing™ user.
Configuring the Disbursement Interface Service
Configuration settings must be specified to control the function of the disbursement interface.
By default, the Disbursement Interface will return an error unless the disbursement interface has been written.
The following table lists the configuration settings for the disbursement interface, and these settings are typically
overridden by a custom request.
