Creating an Agent Commission Account
Users create a Direct Bill Commission account type specifically to collect and distribute agent commission. This
account contains information for each specific agent about that agent's preferred statement format and commission
payment method.
The following ManuScripts are used in the customization of the available account options:
•Billing_Policy_Account_Common_1_0_0_0.xml
•Billing_Commission_Plans_1_0_0_0
•Carrier_Billing_Commission_Plans_1_0_0_0
•Billing_AccountPlanSetup_TemplateDirectBillCommission_1_0_0_0
•Agent_Plans_1_0_0_0
•Carrier_ Agent_Plans_1_0_0_0
Commission payments to agents can be made by check or EFT. When payments are made by check, a file is
automatically created for use with the Duck Creek Billing™ disbursement interface. When the EFT option is selected,
the user must enter bank details for the agent, and a commission payment is processed like any other disbursement.
Any amount that is not paid by EFT or check is returned and applied back to the agent's commission statement to be
included with the next payment.
The Commission Account privilege is required for access to the Account Home page for a direct bill
commission account. For more information, see Creating a Billing User .
