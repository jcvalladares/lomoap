If the scheduled activities fail to process, try the following troubleshooting tips.
Checking Configuration Files
Verify that the settings in the DuckCreek.Utility.ScheduledRequestSvc.exe.config and the
AsyncQueueService.exe.config file are correct. In the Duck Creek root directory (for example, C:\Program Files\Duck
Creek Technologies\) navigate to the appropriate file.
