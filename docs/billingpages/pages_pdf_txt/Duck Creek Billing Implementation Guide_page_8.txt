Configuring Services for Duck Creek Billing™
Services configuration files are located at: C:\Program Files\Duck Creek Technologies\Shared\Bin\DuckCreek.Utility.
To edit these files, open them in a text editor program.
The following services must be configured:
•MSMQBillingListenerSvc.exe.config
•ScheduledRequestSvc.exe.config
MSMQBillingListenerSvc.exe.config
The Microsoft Message Queue (MSMQ) Billing Listener is a message store that enables messages to be read or
written. When a message is read, it is removed from the queue. The MSMQ is accessible via an API.
