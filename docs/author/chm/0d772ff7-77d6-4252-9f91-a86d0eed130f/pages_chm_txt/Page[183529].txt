Data Tester Data Tester Save Section to .PDF Save Page to .PDF You use the Data Tester to create and edit data documents associated with the active ManuScript. After using this data to test the execution of the ManuScript, you can view the results of the execution. When you execute your ManuScript, you can view the output by clicking one of the following tabs: Results — Displays all the fields and results as they are executed. Detailed View — Displays all fields and results as well as additional calculation information. Output XML — Displays the XML data format that would be used by the downstream system.
