Revision Viewer Revision Viewer Save Page to .PDF You use the Revision Viewer to view information on changes made to the ManuScript. The Revisions dialog box will remain blank until the Track Revisions check box is selected. To view the revisions to a ManuScript: On the Tools menu, click View Revisions . The Revisions viewer appears. It displays information on the changes made to the ManuScript. Item Description/Action Revision Date The Version date of the active ManuScript. User Name of the user who made the change. Item Changed Name of the changed ManuScript item. Action Type of change to the ManuScript item. Comments User-entered comments. Change Date Date of change. Change Time Time of change. ManuScripts in report Click Active Version or All Versions to filter the list of changes. Track revisions in active ManuScript Select to enable revision tracking.
