Affects Tab Affects Tab Save Page to .PDF Fields View The Affects tab is used to define how the current field is affected by another field. To define Affects for a field: Click the field. On the Affects tab, click Add . The Reference Select dialog box appears. Click the reference group and field, and then click OK . In the Type list, click the type of affect. The options are: Pre-Effect . Execute the referenced field before the current field is executed. Post-Effect . Execute the referenced field after the current field is executed. Set Value . Change the value of the referenced field to the value of the current field. (Optional) Repeat steps 2–4 to add more Affects.
