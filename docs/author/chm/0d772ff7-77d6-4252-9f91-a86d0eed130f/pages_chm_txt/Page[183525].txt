Data Names Data Names Save Page to .PDF Tables View Data Names in the Table Properties dialog box are the column titles for the table. To add or edit Data Names: Click the table name. Click the Table Properties button . You can also: • On the Edit menu, click Properties . • Double-click the table name. • Right-click the table name, and then click Properties . Enter the new data name into the Data Names text box, or edit an old name. You may also click: Add to add additional lines for data names. Delete to delete a data name.
