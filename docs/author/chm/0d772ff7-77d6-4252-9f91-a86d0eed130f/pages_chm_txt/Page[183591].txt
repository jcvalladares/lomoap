Inheritance Inheritance Save Section to .PDF Save Page to .PDF The EXAMPLE Platform ® uses an inheritance model to develop and deliver ManuScripts. With the inheritance model, you can use any ManuScript as a base to create a new ManuScript. This new ManuScript, derived from the base, can extend or modify any part of the inherited ManuScript. For any ManuScript, you can specify an external ManuScript to inherit for each of the following: Fields and Groups Pages Forms For information about the Duck Creek Templates™ inheritance model, see Duck Creek Templates™ Inheritance 6.0.0.0 .
