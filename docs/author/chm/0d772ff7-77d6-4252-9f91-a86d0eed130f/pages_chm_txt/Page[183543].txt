Converting Sections Converting Sections Save Page to .PDF If desired, you can convert a section to a table or a grid widget. Converting Sections to Tables Page Designer View You can convert a section to a table at any time. When you convert a section to a table, the system applies all applicable properties defined for the section to the new table as they were defined in the section. To convert a section to a table: Click the section you wish to convert. On the Edit menu, click Convert To Table . The selected section appears as a table in the Page Designer list. You can also: Right-click the section, and then click Convert To Table . Converting Sections to Grid Widgets Page Designer View You can convert a section to a grid widget if the section does not contain any child sections, tables, or widgets. When you convert a section to a grid widget, the system forces the following properties to have the following values: Layout Direction — Across Field Caption Position — Above Field Field Caption Display — First Iteration Read-Only Content — True The above properties do not appear in the Properties list for editing. The system applies all other applicable properties defined in the section to the new grid widget as they were defined in the section. To convert a section to a grid widget: Click the section you wish to convert. On the Edit menu, click Convert To Grid Widget . The selected section appears as a grid widget in the Page Designer list. You can also: Right-click the section, and then click Convert To Grid Widget .
