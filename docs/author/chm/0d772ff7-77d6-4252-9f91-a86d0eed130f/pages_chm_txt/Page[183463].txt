ManuScripts ManuScripts Save Section to .PDF Save Page to .PDF ManuScripts are XML files that contain fields, groups, tables, forms, and Web page definitions that fully detail all aspects of an insurance product. A ManuScript: Defines the content, rules, values, and processes needed to manage data by populating or validating a data document containing the information needed by a business process. Enables you to document each product by giving you a powerful engine to collect and process data. ManuScripts contain information to describe the data document and to create product documentation. Provides the definition information needed to generate data entry screens to collect data from an end user.
