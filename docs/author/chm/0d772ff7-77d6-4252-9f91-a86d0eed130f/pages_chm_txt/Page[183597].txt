Viewing and Editing XML Viewing and Editing XML Save Page to .PDF You can update ManuScripts in XML with the XML Viewer dialog box. You can view XML for individual fields or tables, or for the entire ManuScript. Use the buttons on the left hand side of the XML Viewer to expand or collapse the XML view. Viewing XML for a Field To view XML for a field: Click the field. On the Edit menu, click View Field XML . The XML Viewer dialog box appears for the selected field. In this dialog box, you can: Find an item within the XML Edit and update the XML Viewing XML for a Table To view XML for a table: Click the table. On the Edit menu, click View Table XML . The XML Viewer dialog box appears for the selected table. In this dialog box, you can: Find an item within the XML Edit and update the XML Viewing XML for a Page To view XML for a page: Right-click the page, group, layout, or field. Click View Page XML . The XML Viewer dialog box appears for the selected page or for the page containing the selected group, layout, or field. In this dialog box, you can: Find an item within the XML Edit and update the XML Viewing XML for a ManuScript To view XML for a ManuScript: On the View menu, point to XML , and then click Source XML . The XML Viewer dialog box appears for the ManuScript. In this dialog box, you can: Find an item within the XML Edit and update the XML You can also view logical XML or differences XML. Viewing XML Differences To view XML differences for an inherited ManuScript: On the View menu, point to XML , and then click Differences XML . The XML Comparison dialog box appears for the ManuScript. In this dialog box, you can view the differences between the current ManuScript and the base ManuScript. Editing XML To edit XML: Open the XML Viewer dialog box for a field, table, or ManuScript.
