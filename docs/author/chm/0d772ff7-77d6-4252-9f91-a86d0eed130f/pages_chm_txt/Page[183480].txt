Defining Property Value Types Defining Property Value Types Save Section to .PDF Save Page to .PDF You can set the value of many field Properties by selecting a value type and then defining it. Property value types can be selected from drop-down lists associated with these Properties. When you select a value type for a property, the Definition pane includes the information needed to further define the property. The types of property values include the following. Type Value Determination (none) User-entered value. Constant/Field Constant value or field reference. Calculation Result of a calculation. Conditional True or false result based on a condition. Date Result of a calculation using dates. External Value from a field in another ManuScript. Function Value used to determine various field characteristics such as padding, length, and whether to use upper-case or lower-case text. Iterator Result of multiple iterations in terms of a sum, maximum, minimum, or count. Lookup Value extracted from a table. Request Value from an attribute in a request. Select Value returned if the field value is equal to one of a set of specified cases. Session Value of specified data for the current session. Substring Specified portion of a string. Sum/Accumulator Result of an evaluation of the value from all iterations of a specified field in an iterative group. WrittenPrem Written premium value based on the policy data defined in the field. Integration Point Values returned from a third party reporting service. Available only on the Value property.
