External External Save Page to .PDF With an External value type, you specify how to get a value from a field in another ManuScript. You can separate the logic into multiple ManuScripts and access the values and fields found in them. All the ManuScripts involved in external references must use the same data document. When a ManuScript executes a reference to an external field, the referenced ManuScript is executed using the active data document. Any modifications to the content of the data document remain after return from the referenced ManuScript. There are times when the accessed ManuScript may need to be determined at runtime. To compute the ManuScript ID for an External field reference, use another field in the ManuScript to determine the correct ID. It is a best practice to use a field that has a Lookup value type. If you must determine the ManuScript ID at runtime, create a table to hold the possible IDs and access the ID using a lookup. This is the simplest way to manage the ID values and allows the deployment process to publish the list of required external ManuScript IDs. When a ManuScript is deployed, it communicates with the deployment manager and lists all the dependencies that should be deployed with the ManuScript. When a ManuScript accesses another ManuScript through the External value type, the ManuScript must be able to identify the ManuScripts upon which it is dependant. Defining an External Value Fields View To define an External value: In the list for the appropriate property, click External . Enter the ManuScript to access . You can enter a constant value or click the Ellipsis button to use the Reference Select dialog box to select a field reference. Identify the external ManuScript using the unique ID used in the ManuScript Catalog. Because a ManuScript ID is globally unique, it should always correctly identify the target ManuScript. The referenced ManuScript ID must exist in the ManuScript Catalog of the machine on which the execution occurs. You can use the ManuScript Catalog Detail dialog box to view the IDs of ManuScripts. In Field in external ManuScript to access , enter the text name of the field to access in the external ManuScript. You can enter a constant value or click the Ellipsis button to use the Reference Select dialog box to select a field reference. (Optional) If the field being accessed in the external ManuScript is within an iterated group, enter the full Data path of the field to identify the iteration to be used within the data document. Leaving the Data Path empty gets the current iteration, meaning that whatever iteration is active in the calling ManuScript is the iteration in the external ManuScript. It is usually sufficient to leave the Data Path empty. (Optional) Select the Preserve the current data check box. If this option is selected, the Session data is not modified. A copy is sent to the EXAMPLE Server ® . If this option is cleared, the actual Session data is used and may be modified. In the All data changes are discarded other than the contents of the following group list, click the group that is not to have its content discarded. When a group is selected, the data changes from the EXAMPLE Server ® for that group are preserved.
