Actions Actions Save Page to .PDF Actions are buttons that can be placed in a group, section, table, or grid widget. You can add or remove actions, or define properties for actions. Adding an Action Page Designer View To add an action: Click the appropriate section, table, or grid widget. On the Edit menu, click Insert action . You can also: Right-click a section, table, or grid widget, and then click Insert action . Define the properties for the action. Deleting an Action Page Designer View To delete an action: Select the action you wish to delete. Click the Delete button . In the Confirm dialog box, click Yes to confirm the deletion, or No to cancel. Defining Actions Page Designer View To define an action, you specify the following properties. You define requests in the Request Command and Name Value Definitions dialog box. Setting the Action Type Property Page Designer View You can define the following types of actions. Action Description Delete Record (sections/tables/grid widgets) Deletes an iteration of an object from the session data document. The default behavior returns to the current page after the object is deleted. If you specify a page or PageSet, EXAMPLE Server ® deletes the object and then goes to the new page. Duplicate Record (sections/tables/grid widgets) Duplicates an iteration of an object in the session data document. The default behavior returns to the current page after the object is duplicated. If you specify a page or PageSet, EXAMPLE Server ® duplicates the object and then goes to the new page. Add Record (groups) Adds an iteration of an object to the session data document. The default behavior returns to the current page after a new object is added. If you specify a page or PageSet, EXAMPLE Server ® adds the object and goes to the new page that contains only the iteration of the newly added object. Goto Page Routes the interview to a different destination. Under normal circumstances the Goto Page destination is determined when the page is rendered. However, it is possible to determine the Goto Page destination after the button is pressed. To determine the destination page after the button is clicked: Enter the name of a field containing the name of the destination page, prefixed by a $ (dollar sign). When the <ManuScript.getPageRq> request is processed and the value of the Goto Page command begins with a $ , the specified field is executed to determine the name of the page or PageSet to which to route. Calculate (discard results) Calculates the ManuScript and do not preserve the calculated results in the session data document. Calculate (keep results) Calculates the ManuScript and preserve the calculated results in the session data document. Detail for this Record (sections/tables/grid widgets) Displays fields for a single iteration. If you specify a page or PageSet, the detail displays on the specified page. (The root group for a page displaying a single iteration must be the iterating group.) This action cannot be used to retrieve data stored in named documents. Iteration Links (groups) Returns a set of actions in conjunction with iterating objects. The number of actions depends on the current number of repeating objects in the data document for the context of this group and the values in the following Iterations fields: Maximum — Each action displays only the number of objects entered in the Maximum field for the specified PageSet. Links — The value in the Links fields specifies the maximum number of actions returned on a page. Custom Action Executes a <getPageRq> request that contains an attribute of command = "custom" . This indicates to the application that custom processing must occur. The setting of command="custom" is ignored by EXAMPLE Server ® . Mark-for-Delete (sections/tables/grid widgets) Deletes an iteration of an object in the session data document. To set the value of the Action Type property: Click the action. On the Definition tab, click Action Type . In the Action Type list, click the appropriate option. The action type is added to the selected action in the Page Designer list. Setting the Page Property Page Designer View The Page property specifies the page to be loaded when the action is Goto Page. This value can be determined at two different times: When the page containing the action is rendered When the action is clicked By default, the value of this property is determined when the page containing the action is rendered. To determine the value of the property when the action is clicked, you must specify the field to execute when the action is clicked, prepending the field name with a dollar sign ($) and surrounding the entire expression with quotations marks (e.g., "$FieldName" ). To set the value of the Page property: Click the action. On the Definition tab, click Page . Specify a value, or, to the right of the Page text box, click the Ellipsis button to use the Reference Select dialog box to select a field. If the system should determine the value of the property when the action is clicked, prepend the field name with a dollar sign ($) and add quotation marks around the entire expression (e.g., "$FieldName" ).
