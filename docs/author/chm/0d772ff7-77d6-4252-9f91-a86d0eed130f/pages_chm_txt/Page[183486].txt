Function Function Save Page to .PDF ManuScript functions serve as shorcuts for applying commonly-used field formatting. With a Function value type, you apply one of several possible functions to a specified field. The following table lists the functions available out of the box for use with the Function value type. Function Description String.Contains Determines whether a string is contained within another string. String.CountItems Counts the number of entries in a delimited string. String.Format Formats a string according to the specified format mask and ManuScript culture. Primarily used to format numbers and some date formatting. String.HashMD5 Returns a MD5 hash of the string. String.IsNumeric Determines whether the string is a numeric value. The IsNumeric function can be used with all culture settings and comma separators. String.Lookup Retrieves a value within a specifically delimited string of key/value pairs given the key and delimiters. String.LowerCase Converts a string to its lower-case equivalent. String.Left Retrieves a portion of a string starting from the front of the string given the number of characters to retrieve. String.Length Counts the number of characters in a string. String.PadRight Appends a string to a given length with a specified character. String.PadLeft Prepends a string to a given length with a specified character. String.RegExMatch Returns true if the string contains a match for the specified regular expression. The .NET RegEx parser is used. String.Replace Replaces a string within another string with a new string. String.Right Retrieves a portion of a string starting from the end of the string given the number of characters to retrieve. String.Trim Removes leading and trailing white space from a string. String.UpperCase Converts a string to its upper-case equivalent. Adding Custom Functions You can create custom functions and add them to EXAMPLE Author ® by extending the ManuScriptFunctions_custom.xml file located in the Shared directory in the Duck Creek root directory (for example, C:\Program Files\Duck Creek Technologies \Shared ). To add a new function: In the ManuScriptFunctions_Custom.xml file, add all the desired functions, following the same syntax found in the ManuScriptFunctions.xml file. To avoid losing custom functions during an upgrade, never add them to the ManuScriptFunctions.xml file. Defining a Function Value Type in EXAMPLE Author® Fields View To define a function value: In the dropdown list for the appropriate property, click Function . In the Function list, click the appropriate function option. The type of value returned by the function is displayed and the following possible function options appear: Source Item Separator Item Separator *Key Separator Key Length Count Character The function options available are determined by the type of function selected in the Function list. Enter the value for each function option available.
