Page Designer Controls Page Designer Controls Save Page to .PDF You control Page Designer using buttons, menus, and keyboard shortcuts. Page Designer Edit Menu The Edit menu for Page Designer includes the following options. Menu Option Action Undo (CTRL+Z) Undoes the last action performed. Add Page Set Opens the Add PageSet dialog box to add a PageSet to Page Designer. Add Page Adds a page to a PageSet. Add Group (CTRL+G) Adds a group to a layout or header. Add Layout (CTRL+L) Adds a layout to a layout. (Version 1 pages only) Add Section (CTRL+ALT+S) Adds a section to a section or table. (Version 2 pages only) Add Table (CTRL+ALT+T) Adds a table to a section or table. (Version 2 pages only) Convert To Section Converts a table or grid widget to a section. (Version 2 pages only) Convert To Table Converts a section or grid widget to a table. (Version 2 pages only) Convert To Grid Widget Converts a section or table to a grid widget. (Version 2 pages only) Add Widget See Add Widget Submenu for widget options. Insert field (CTRL+A) Adds a new field to a layout. Insert action (CTRL+ALT+A) Adds an action to a section, table, or grid widget. (Version 2 pages only) Auto-associate fields Inserts a field and all fields used by the selected field into the layout. Used by (CTRL+U) Opens the Usage dialog box to list the items that use the selected field. To go to a field, click Go to . Delete Deletes the selected PageSet, page, group, layout, or field in Page Designer. Demote/Revert Removes local definition, returning item to derived status. Rename Changes the name of the selected item. Find (CTRL+F) Opens the Search dialog box to enter text to find. Find Next (F3) Finds the next occurrence of the previously entered text. Duplicate (CTRL+D) Opens the Duplicate Layout dialog box. Annotations (CTRL+T) Adds or edits an annotation for the selected item. Refresh List (F5) Refreshes the Page Designer list. View Page XML Opens the XML Viewer dialog box for the selected page. Compare XML Opens the XML Comparison dialog box to compare the current XML with the base XML. Move Left (CTRL+ALT+L) Moves the selected item left in the list. (Promote) Move Up (CTRL+ALT+U) Moves the selected item up in the list. Move Down (CTRL+ALT+D) Moves the selected item down in the list. Move Right (CTRL+ALT+R) Moves the selected item right in the list. (Demote) Add Widget Submenu The Add Widget submenu contains the following options. Menu Option Action Add Accordion Widget Adds an accordion widget to a section or table. (Version 2 pages only) Add Comparison Widget Adds a comparison widget to a section or table. (Version 2 pages only) Add Grid Widget (CTRL+ALT+G) Adds a grid widget to a section or table. (Version 2 pages only) Add Progress Bar Widget Adds a progress bar widget to a section or table. (Version 2 pages only) Add XHTML Widget (CTRL+ALT+X) Adds an XHTML widget to a section, table, or grid widget. (Version 2 pages only) This menu is also available in the shortcut menu for the Page Designer list. Page Designer Toolbar Buttons The Page Designer toolbar contains the following buttons. Button Name Action Add Page Set Opens the Add PageSet dialog box to add a PageSet to Page Designer. Add Page Adds a page to a PageSet. Add Group Adds a group to a layout or header. Add Layout Adds a layout to a layout. (Version 1 pages only) Insert Field Adds a new field to a layout. Delete Deletes the selected PageSet, page, group, layout, or field in Page Designer. Refresh List Refreshes the Page Designer list. Move Up Moves the selected item up in the list. Move Down Moves the selected item down in the list. Move Left Moves the selected field left in the list, making it a child of the parent layout. (Promote) Move Right Moves the selected field right in the list, making it a child of the child layout.
