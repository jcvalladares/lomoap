Converting a Page (from Version 1) Converting a Page (from Version 1) Save Page to .PDF The Page Converter converts Version 1 pages to Version 2 pages. With the Page Converter, you can convert a single page in a ManuScript or all pages local to a ManuScript. The conversion process performed by the Page Converter tool is final. Version 2 pages cannot be converted back to Version 1. Back up ManuScripts before converting pages to Version 2. Only pages local to the current ManuScript are converted. During conversion, the Page Converter performs the following actions: Converts Version 1 page elements (such as layouts) to Version 2 page elements (such as sections). When converting pages, all layouts are converted to sections. Converts any layout with the Field Caption Display property defined as "First Iteration" to a section with a Field Caption Display property defined as "All". Because sections cannot contain iterations, the First Iteration option for the Field Caption Display property is not valid for sections. Applies all custom parameters defined in Version 1 pages to Version 2 pages. Any custom parameter defined in Version 1 pages with an equivalent advanced property in Version 2 pages is converted to that advanced property. Any custom parameter that does not have an equivalent advanced property in Version 2 pages is added to the Version 2 page as a Custom Property . Custom properties appear below all other properties. All custom properties are italicized. For a list of Version 1 custom parameters supported in Version 2, see Conversion Support for Custom Parameters . When a custom parameter from a version 1 page is added as a custom property to a version 2 page during conversion, you should evaluate whether any of the standard properties for version 2 pages already accomplish what is specified in the custom property. If the standard properties do not accomplish what is needed, you must customize your skin to accommodate the custom property. After page conversion, you can convert any desired sections to different elements (tables or grid widgets) and modify any desired properties. You can also remove any nested sections converted from a Version 1 page that are unnecessary in Version 2. To open the Page Converter: On the Tools menu, click Page Converter . Converting a Single Page Converting a single page from Version 1 to Version 2 requires you to: Convert the page using the Page Converter tool. Remove any unnecessary page elements (such as nested sections) carried over during conversion. Modify any desired page elements or properties that were altered upon conversion. When converting pages from Version 1 to Version 2, the system automatically converts all layouts to sections. If you wish some layouts to become tables or grid widgets, you must manually convert these sections to tables or grid widgets after page conversion. Converting the Page To convert the page using the Page Converter tool: On the Tools menu, click Page Converter . The Page Converter dialog box appears. Click the Convert a single page option. Click the PageSet containing the page you wish to convert, and then click the Page you wish to convert. Click Continue . A warning message appears. To continue with the conversion process, select the Yes, I understand check box, and then click Continue . A process dialog box appears, indicating the progress of the conversion. When complete, a success confirmation dialog box appears. In the success confirmation dialog, click OK . The page will appear as a Version 2 page in the Page Designer list. Click Save to save conversion changes. You must save changes before exiting EXAMPLE Author ® to retain conversion changes. Removing Unnecessary Page Elements To remove any unnecessary page elements (such as nested sections) carried over during conversion: In a section containing unnecessary nested sections, move fields and actions to the highest section in the hierarchy of nested sections. Delete all empty child sections. Modifying Page Elements and Properties To modify any desired page elements or properties that were altered during conversion: (Optional) Convert any desired sections to different elements (tables or grid widgets). (Optional) Modify any desired properties. Because sections do not support iterations, all layouts with a Field Caption Display property set to First Iteration are converted to sections with a Field Caption Display property set to All . To change this property, modify the property for the section, or convert the section to a table or grid widget and adjust the Field Caption Display property. Converting All Pages in a ManuScript The Page Converter only converts pages that are local to the current ManuScript. Converting all local pages in a ManuScript from Version 1 to Version 2 requires you to: Convert the pages using the Page Converter tool. Remove any unnecessary page elements (such as nested sections) carried over during conversion. Modify any desired page elements or properties that were altered upon conversion. When converting pages from Version 1 to Version 2, the system automatically converts all layouts to sections. If you wish some layouts to become tables or grid widgets, you must manually convert these sections to tables or grid widgets after page conversion. Converting Pages To convert the pages using the Page Converter tool: On the Tools menu, click Page Converter . The Page Converter dialog box appears. Click the Convert all pages defined in this ManuScript option, and then click Continue . A warning message appears. To continue with the conversion process, select the Yes, I understand check box, and then click Continue . A process dialog box appears, indicating the progress of the conversion. When complete, a success confirmation dialog box appears. In the success confirmation dialog, click OK . The pages will appear as Version 2 pages in the Page Designer list. Click Save to save conversion changes. You must save changes before exiting EXAMPLE Author ® to retain conversion changes. Removing Unnecessary Page Elements To remove any unnecessary page elements (such as nested sections) carried over during conversion: In a section containing unnecessary nested sections, move fields and actions to the highest section in the hierarchy of nested sections. Delete all empty child sections. Modifying Page Elements and Properties To modify any desired page elements or properties that were altered during conversion: (Optional) Convert any desired sections to different elements (tables or grid widgets). (Optional) Modify any desired properties. Because sections do not support iterations, all layouts with a Field Caption Display property set to First Iteration are converted to sections with a Field Caption Display property set to All . To change this property, modify the property for the section, or convert the section to a table or grid widget and adjust the Field Caption Display property. Conversion Support for Custom Parameters During conversion to Version 2 pages, the Page Converter supports all custom parameters defined in Version 1 pages by: Converting any custom parameters supported by Version 2 pages to the equivalent advanced properties Adding any custom parameters not supported by Version 2 pages (that is, any parameters that do not have equivalent advanced properties) as Custom Properties . Custom properties appear below all other properties. When a custom parameter from a version 1 page is added as a custom property to a version 2 page during conversion, you should evaluate whether any of the standard properties for version 2 pages already accomplish what is specified in the custom property. If the standard properties do not accomplish what is needed, you must customize your skin to accommodate the custom property.
