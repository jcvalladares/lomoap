Best Practices for Building Version 2 Pages Best Practices for Building Version 2 Pages Save Page to .PDF When building version 2 pages, consider the following Best Practices: When working with iterative data, place fields within a table or grid widget. When working with non-iterative data: If field captions and data can be centered, place fields within a section. If field captions and data must be left-aligned, place fields within a table. Field captions and data within a section may be left-aligned by hardcoding a pixel width for the caption of each field to be aligned. Instead of adding extra spacer elements to position page elements on pages, rely on CSS styles. Limiting the number of page elements used to position items reduces the amount of HTML that must be generated and reduces the number of CSS rules that must be applied to render pages appropriately. Use XHTML widgets sparingly. XHTML widgets break consistency with the structure and styles applied to normal interview pages and page elements, making maintenance of interview pages more difficult. The use of multiple grids per page is not supported.
