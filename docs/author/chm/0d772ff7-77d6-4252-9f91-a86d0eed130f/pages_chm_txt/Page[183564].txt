Importing Pages Importing Pages Save Page to .PDF Page Designer View To import pages into a ManuScript: On the File menu, click Import . The Import Wizard dialog box appears. Click Catalog . The ManuScript Catalog dialog box appears. Click the ManuScript from which to import, and then click Load . Click Import Pages , and then click Next . The pages in the selected ManuScript are displayed in the Select the items to import list. Click the pages to import. If you select a page, you automatically select all elements within the page. Click Next . The elements to be imported are listed. Any items selected in the previous display that already exist in the current ManuScript are not selected for importing. The list includes any groups, fields, and tables that the pages reference. You can clear any element you do not want to import by clearing the check box. You can force the importation of an element already in the current ManuScript by selecting the appropriate check box or by clicking the Mark All button . Click Finish . All selected items are imported into the ManuScript.
