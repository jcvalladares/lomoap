CSS Manager CSS Manager Save Page to .PDF The CSS Manager allows you to add, delete, and define custom CSS styles that can be applied to various page elements. The CSS styles defined in the CSS Manager can be applied to: Pages Sections Tables Grid widgets XHTML widgets Fields Actions The CSS Manager reads from and writes to the x_interview.css override file in the [GlobalRootPath]\Express\Skins\ [SkinName] \css directory. From the CSS Manager, you can access and edit the x_interview.css override file. The x_interview.css override file is shipped with several out-of-the-box override styles. From the CSS Manager, you can add to, delete, or modify these styles. Adding a New Style To add a new style in CSS Manager: On the Tools menu, click CSS Manager . The CSS Manager dialog box appears. Click Create New . The Create New dialog box appears. Enter the Class Name for the style, and then click OK . The new style appears in the Style list. In the Definition pane, define the style by performing one of the following actions: Click a property from the list of properties, and then click Insert . You can also: Double-click the desired attribute. Define the property in the text box. Enter the desired definition in the text box. When finished, click Apply to save the definition and continue working in CSS Manager, or click OK to save the definition and close CSS Manager. Deleting a Style Before deleting a style in CSS Manager, verify the style is not used in any ManuScripts using the x_interview.css file. To delete a style in CSS Manager: On the Tools menu, click CSS Manager . The CSS Manager dialog box appears. In the Style list, click the style you wish to delete. Click Delete . A confirmation dialog box appears. In the confirmation dialog, click Yes . Modifying a Style To modify a style in CSS Manager: On the Tools menu, click CSS Manager . The CSS Manager dialog box appears. In the Style list, click the style you wish to modify. In the Definition pane, modify the style as desired. When finished, click Apply to save the definition and continue working in CSS Manager, or click OK to save the definition and close CSS Manager.
