Converting Tables Converting Tables Save Page to .PDF If desired, you can convert a table to a section or a grid widget. Converting Tables to Sections Page Designer View You can convert a table to a section at any time. When you convert a table to a section, the system applies all applicable properties defined for the table to the new section as they were defined in the table, with one exception. If the Field Caption Display property for the table is set to First Iteration , the system will reset the value of this property to All upon conversion. (The First Iteration option for the Field Caption Display property is not valid for sections.) To convert a table to a section: Click the table you wish to convert. On the Edit menu, click Convert To Section . The selected table appears as a section in the Page Designer list. You can also: Right-click the table, and then click Convert To Section . Converting Tables to Grid Widgets Page Designer View You can convert a table to a grid widget if the table does not contain any child sections, tables, or widgets. When you convert a table to a grid widget, the system forces the following properties to have the following values: Layout Direction — Across Field Caption Position — Above Field Field Caption Display — First Iteration Read-Only Content — True The above properties do not appear in the Properties list for editing. The system applies all other applicable properties defined in the table to the new grid widget as they were defined in the table. To convert a table to a grid widget: Click the table you wish to convert. On the Edit menu, click Convert To Grid Widget . The selected table appears as a grid widget in the Page Designer list. You can also: Right-click the table, and then click Convert To Grid Widget .
