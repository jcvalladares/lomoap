XHTML Widgets XHTML Widgets Save Page to .PDF XHTML widgets allow you to define HTML markup to be inserted at any point on a page. XHTML widgets must contain HTML that is both valid HTML and valid XML. XHTML widgets cannot contain sections, tables, grid widgets, fields, or actions. Because XHTML widgets break consistency in page structure and styling, Duck Creek Technologies, Inc. recommends using XHTML widgets only when necessary. You can add or remove XHTML widgets and define properties for them. XHTML widgets can be nested within sections or tables. Adding an XHTML Widget Page Designer View To add an XHTML widget: Click the section or table under which to add an XHTML widget. On the Edit menu, click Advanced , and then click Add XHTML Widget . You can also: •Press CTRL+ALT+X. •Right-click a section or table, click Advanced , and then click Add XHTML Widget . Deleting an XHTML Widget Page Designer View To delete an XHTML widget: Select the XHTML widget you wish to delete. Click the Delete button . In the Confirm dialog box, click Yes to confirm the deletion, or No to cancel. Defining XHTML Widget Properties Page Designer View To define an XHTML widget, you specify the following properties. Property Description General Name Name of the XHTML widget. Data XHTML Content HTML markup to place on the page. Display XHTML Caption Text to describe the XHTML widget. XHTML Caption Style CSS styles to apply to the XHTML caption. Styles apply according to CSS inheritance rules. XHTML Style CSS styles to apply to the XHTML widget content. Styles apply according to CSS inheritance rules. Setting the Name Property Page Designer View The Name property contains the name of the XHTML widget. This name appears on the XHTML widget in the Page Designer list. To set the value of the Name property: Click the XHTML widget. On the Definition tab, click Name . Enter the XHTML widget name. Setting the XHTML Content Property Page Designer View The XHTML Content property specifies the HTML markup to place on the page. To set the value of the XHTML Content property: Click the XHTML widget. On the Definition tab, click XHTML Content . Specify a value, or, to the right of the XHTML Content text box, click the Ellipsis button to use the Reference Select dialog box to select a field. Setting the XHTML Caption Property Page Designer View The XHTML Caption property contains the text to display as the title of the XHTML widget. To set the value of the XHTML Caption property: Click the XHTML widget. On the Definition tab, click XHTML Caption . Enter the XHTML caption. Setting the XHTML Caption Style Property Page Designer View The XHTML Caption Style property specifies the CSS styles to apply to the caption of the XHTML widget. Styles specified in this property will override any global CSS styles assigned. Styles apply according to CSS inheritance rules. To set the value of the XHTML Caption Style property: Click the XHTML widget. On the Definition tab, click XHTML Caption Style . To the right of the XHTML Caption Style text box, click the CSS button to use the CSS Selector dialog box to select the desired styles. Setting the XHTML Style Property Page Designer View The XHTML Style property specifies the CSS styles to apply to the content of the XHTML widget. Styles specified in this property will override any global CSS styles assigned. Styles apply according to CSS inheritance rules. To set the value of the XHTML Style property: In Page Designer, click the XHTML widget. On the Definition tab, click XHTML Style . To the right of the XHTML Style text box, click the CSS button to use the CSS Selector dialog box to select the desired styles.
