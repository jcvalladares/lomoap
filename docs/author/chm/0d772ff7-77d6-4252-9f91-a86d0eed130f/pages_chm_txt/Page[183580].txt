Constant Viewer Constant Viewer Save Page to .PDF You use the Constant Viewer to view all of the constant values within the ManuScript. The Constant Viewer allows you to sort, find, and edit field values. To open the Constant Viewer: On the Tools menu, click Constant Viewer . You can also: Press F8. Viewing Constants To view constant values: Select the visibility to display. Select the Public or Private check box, or both. Click the Fields to view list. Click one of the following options: Fields with defined value only — Displays only fields with the defined value. Fields with value or undefined — Displays only fields with the defined value, or undefined values. All Fields — Displays all fields in the ManuScript. Click a Property Name to view . Options include all field properties. Click an option for Sort Fields by . Click one of the following options: Whole name — Sort the fields alphabetically by the entire prepended name. Right side only — Sort the fields alphabetically by field name without any prepended group name. (Optional) Click Columns to open the Property Names dialog box to choose additional columns to display in the Constant Viewer. Editing Constants To edit constant values for public fields using the Constant Viewer: In the Constant Viewer, set the parameters to view the appropriate constants in the list. In the list, click the row associated with the constant to edit. Enter a value for a property in the appropriate column. Click the Ellipsis button to use the Reference Select dialog box to select a field reference. Double-click a field name in the Constant Viewer to open the Fields View.
