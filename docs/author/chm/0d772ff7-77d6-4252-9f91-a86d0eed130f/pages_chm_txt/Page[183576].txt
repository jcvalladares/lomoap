Validator Validator Save Page to .PDF The Validate pane includes the controls for and results of ManuScript validation. To open the Validate pane: Click the Validate button . You can also: On the Tools menu, click Validate . Validations The Validator may return a warning or an error if it encounters any of the following: Definitions A field has an option list and there is a value in the value tab. A value is used twice within an option list for a field. The default value is different than the default value set in Options. A condition has a duplicate value in the pick list. The data type specified is not valid for the option values used. A (defined) option is empty. A notify option is empty. Miscellaneous rules have been defined but are empty. (Defined) rules are empty. Values A primary value is not selected in the properties of a field. A select value type has an invalid value or reference. Invalid operators exist in any string calculation. A public field has a set minimum. Comparisons of is , isnot or contains are followed by a value type other than string. Data Types A date method has invalid arguments. A substring has no value or reference for base string, start position, or length. The data type used for the session is not valid. A single condition rule is not defined as boolean. A conditional statement has mismatched data types. Paths No path is specified for a field. A path is used by multiple fields in the ManuScript. Coded items in a path are invalid. A group path is not valid for the Data Schema. Group A group level is invalid for a table or a table field does not have access to a group. A group is not mapped to a valid object. Pages A field is used more than once in a PageSet. Topics of iteration links have the same name as a PageSet. PageSet names contain spaces. Iterations Iterator reference groups have an invalid reference field (if not a count). An iterator reference field does not exist. The conditions of an iterating field are defined outside of that field's group. Calculation rules exist on an iterating field with the new Subtotal check box selected. An invalid context of reference groups is used to restrict iterations for an iterator field type. Forms A print job name uses invalid characters. A merge field or mapped file is missing. Tables A lookup references an invalid table. A key of a table is unused or has no value or reference specified. A table does not have at least one key, either row or column. Row data exceeds the number of keys defined for a table. Indexes in a conditional table are not sequential. A table has been overridden in an inherited ManuScript, but it has then been reverted to match the base ManuScript. References A message referenced by a field does not exist in the message block. An external name points to a missing ManuScript or field. A field is used more than once in the Database Mapping tool. A database mapping reference does not exist. For Request value types, an incorrect Request Command was entered or a Response Attribute does not exist. Other Fields or tables may be unused in the ManuScript. These are called orphans. Invalid characters exist, such as a group name or ID which begins with a number. A field has been overridden in an inherited ManuScript, but it has then been reverted to match the base ManuScript. Setting Validator Options To set the validation level select or clear the appropriate check boxes. Item Action Validate against ManuScript Schema Warns if the ManuScript is not a valid ManuScript file. A ManuScript must pass this validation for EXAMPLE Server ® to recognize it. Click the Browse button to select an appropriate schema. Validate paths against Data Schema Warns if paths in the current ManuScript fail to match those in the schema. Click the Browse button to select an appropriate schema. Check for errors only Warns if any errors are encountered. Selecting this check box disables all other validator options. Check for orphaned fields/tables/messages Warns if any orphans are detected. Note that these items may be used by external ManuScripts. Check for captions on all public fields Warns if any public field has no Caption. All public fields must have annotations Warns if any public field has no annotation. Check for references to missing fields Checks for references to fields assumed to be local that do not exist in the local ManuScript. Warn if field has no rules or definition Warns if a field has an incomplete definition. Public fields must have maximum length defined Warns if a public field has no Maximum Length defined. Check for minimums on all public fields Warns if a public field has no Minimum defined. Flag overridden fields/tables that are the same as the base Warns if a field has been overridden in an inherited ManuScript but was then changed to match the base ManuScript. If a ManuScript has many field reference problems, selecting Validate against ManuScript Schema may cause the validation process to fail. In a ManuScript with many reference problems, clear the Validate against ManuScript Schema check box before validating. Validating a ManuScript To validate a ManuScript: In the Validate pane, click Validate ManuScript . The ManuScript validates completely and the Validator window displays the results. Review the Status and description of any errors or warnings. Double-click an item in the list to display it in Fields view. (Optional) Select the Ignore check box to skip a given warning during future validations. This check box is only available for warnings. Errors cannot be ignored.
