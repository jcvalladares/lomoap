PageSets PageSets Save Page to .PDF You can add or remove PageSets, and define PageSet properties. Adding a PageSet Page Designer View To add a PageSet: Click the Add PageSet button . The Add PageSet dialog box appears. Enter the new PageSet name,and then click OK . Deleting a PageSet Page Designer View To delete a PageSet: Click the PageSet you wish to delete. Click the Delete button . In the Confirm dialog box, click Yes to confirm the deletion or No to cancel. Defining PageSet Properties Page Designer View To define a PageSet, specify the following properties: Property Description PageSet Name Name of the PageSet. Caption Name of the PageSet as the user sees it. Purpose Purpose of the PageSet. Options are: Main Interview PageSet Linked Interview PageSet Printable Pages Documentation Other Stylesheet XSLT file used to transform the page. Show PageSet Condition indicating whether the PageSet is displayed. Currently, EXAMPLE Express ® does not support this feature. Rule Set The Rule Set property specifies a special set of rules (defined in EXAMPLE Express® skins) to apply to all pages in a PageSet. These rules can control the display or behavior of these pages. Out of the box the following rule set is available: topNav — Changes the default left-navigation layout to a top-navigation layout. Setting the PageSet Name Page Designer View The PageSet Name property specifies the name of the PageSet as the user sees it. To set the value of the PageSet Name property: Click the PageSet. On the Definition tab, click PageSet Name . Enter the name. The PageSet name changes in the Page Designer list. Setting the PageSet Caption Page Designer View The Caption property specifies the name of the PageSet as the user sees it. To set the value of the Caption property: Click the PageSet. On the Definition tab, click Caption . Enter the caption text. Setting the PageSet Purpose Page Designer View The Purpose property specifies the purpose of the PageSet. This property is important to EXAMPLE Express ® and to other applications using EXAMPLE Platform ® page requests to render interview pages. It allows you to categorize the PageSet in such a way that the downstream system can reference the correct pages based on the context of the application. For example, when you start a new quote, EXAMPLE Express ® uses the "Main Interview PageSet." To render an on-line product manual, however, EXAMPLE Express ® uses the appropriate "Documentation" PageSet. To set the value of the Purpose property: Click the PageSet. On the Definition tab, click Purpose . In the Purpose list, click the appropriate purpose. The Purpose property includes the following options. Purpose Description Main Interview PageSet Defaults interview pages when a new quote or policy is started or a stored quote or policy is loaded in EXAMPLE Express ® . Linked Interview PageSet Pages to be referenced as a hyperlink from a Main Interview PageSet. Printable Pages Pages associated with an actualprintable form. When using the DCT forms package, link these pages with the appropriate forms in the Forms Mapper view. Other implementations may link them directly to a printable HTML or XSL file. Documentation Pages associated with an XSLT style sheet that can be used to republish the ManuScript information into a readable or printable documentation set such as an online manual which has linked values to tables, algorithms, annotations, and so on. Other Miscellaneous category for customers who design pages that can be referenced in a fashion different from those already specified. Setting the PageSet Stylesheet Page Designer View The Stylesheet property specifies the XSLT file used to transform the page. To set the value of the Stylesheet property: Click the PageSet. On the Definition tab, click Stylesheet . Enter the style sheet. Setting the Show PageSet Property Page Designer View This setting is included for use in third-party downstream systems and is not supported by EXAMPLE Express ® . The Show PageSet property specifies a condition indicating whether the PageSet is displayed. To set the value of the Show PageSet property: Click the PageSet. On the Definition tab, click Show PageSet . To the right of the Show PageSet text box, click the Ellipsis button to use the Reference Select dialog box to select a boolean field. Setting the Rule Set Property Page Designer View The Rule Set property specifies the name of the rule set used to style pages in the PageSet. These rules can control the display or behavior of these pages. Out of the box the following rule set is available: topNav — Changes the default left-navigation layout to a top-navigation layout. To set the value of the Rule Set property: Click the PageSet. On the Definition tab, click Rule Set . In the Rule text box, enter the name of the rule set you wish to use.
