Setting Field Paths Setting Field Paths Save Page to .PDF Fields View The Data Path property is the element or attribute of the XML data document where the group is mapped or that contains the value of the field. To change or add a path to a field, the field must be public, and a schema must be defined for the ManuScript. To set the Data Path property: Click the field or group. On the Definition tab, click Path . The Path Selector dialog box appears. Click the item from the pre-determined schema to develop a path. Click OK .
