With a Session value type, you can access the values of the active session. The value comes from either the active data document or from system information.

Defining a Session Value

Fields View

To define a Session value:

  1. In the dropdown list for the appropriate property, click Session.
  2. In the Session Value to access list, click the appropriate value:

    The following options are available.

    Option

    Description

    Current Context

    Context currently using the ManuScript.

    Current Date

    Date at the time of execution.

    ManuScript Name

    Caption of the active ManuScript.

    ManuScript ID

    ManuScript ID of the active ManuScript.

    Active UserName

    Name of the current user logged into the system.

    Active PolicyID

    ID of the last accessed policy.

    History ID

    ID of the last transaction stored to the database.

    Version ID

    Version ID of the last accessed ManuScript.

    Current Date/Time

    Date and time of execution.

    Current Time

    Time of execution.

    Active User SecurityLevel

    Security level for the active user.

    Current Form Name

    Name of the current form.

    Current Form Caption

    Caption of the current form.

    Portfolio ID

    ID of the Portfolio.
