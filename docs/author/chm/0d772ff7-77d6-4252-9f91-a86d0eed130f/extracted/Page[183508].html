Fields View

The Worksheet value specifies whether to include the field in the rating worksheet.

To set the value of the Worksheet property:

  1. Click the field.
  2. In the Worksheet list, click the appropriate value type.

    For a field to be included in a rating worksheet, this value must be set to defined.

  3. Set any of the following properties for the field's display in the rating worksheet.

    Option

    Description

    Condition Builder

    Specifies conditions for including the field in the rating worksheet. For more information, see Conditional.
    Always Include Includes the field value in the worksheet data, even if the value is non-altering.

    Exclude Children

    Excludes child fields from the rating worksheet.

    Caption

    Specifies the caption to display on the rating worksheet. (Does not affect screen name display.) Field or string value.

    Format Mask

    Specifies the format mask to be applied when displaying the field on the rating worksheet. (Does not affect screen name display.) Field or string value.

    Summarize

    Controls the output of the rating worksheet. Allows user to see values of the selected factors.

    If the above properties are not defined, the system will use field display definition.
