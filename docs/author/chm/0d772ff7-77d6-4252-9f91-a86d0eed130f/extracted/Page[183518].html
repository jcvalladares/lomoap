Setting the Read Only Property

Save Page to .PDF

Fields View

You can set any public field to Read Only. This tells EXAMPLE Express® or other downstream system that the field is only for display.

To set the value of the Read Only property:

  1. Click the field.
  2. On the Definition tab, in the Read Only list, click the appropriate value type.

    The Read Only property is most often defined as a Conditional value type because it is a boolean property.

    For more information, see Defining Property Value Types.

  3. Complete the definition pane for the value type.

    The result must be either 1 (for true) if the field is read only, or 0 (for false) if the field is not read only.
