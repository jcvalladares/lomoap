Lookup

With a Lookup value type, you access values from a table in the ManuScript. The Lookup type specifies the table to be accessed, the name of the data item in the table to be extracted, and the values used to access the keys of the table.

Defining a Lookup Value Using an Existing Table

Fields View

To define a Lookup value using an existing table:

  1. In the dropdown list for the appropriate property, click Lookup.
  2. In the Table to access list, click the table to use for the lookup.

    Once a table is selected, the rest of the details reflect the information for the selected table:

    • The Data name list includes the data names from the table.
    • The Keys grid lists the keys defined for the table.
  3. (Optional) Click Determine table accessed and then enter a table name and (optional) an external ManuScript ID.

    This feature allows you to determine the actual table used at runtime. Select the option and a field that returns the text name of the table to be accessed. Any table to be accessed by this lookup must have the same Data Name and list of Key Names as the selected table. You can also enter a ManuScript ID if the table is contained in an external ManuScript.

  4. In the Data name list, click the data name from the table to use for the lookup.
  5. Enter a Value To Find for each Key Name.

    You can enter a constant value or click the Ellipsis button  to use the Reference Select dialog box to select a field reference.

Defining a Lookup Value Using a Custom Defined Table

 Fields View

To define a Lookup value using a custom defined table:

  1. In the dropdown list for the appropriate property, click Lookup.
  2. In the Table list, click (custom defined).
  3. Select the Determine table accessed check box and then enter a table name and (optional) an external ManuScript ID.

    You can enter a constant value or click the Ellipsis button  to use the Reference Select dialog box to select a field reference.

  4. In the Data name list, enter a data name to use for the lookup in the table.
  5. Enter Key Names for the table.

    The Data name and all Key Names must be the same in each potential table to use.

  6. Enter a Value To Find for each Key Name.

    You can enter a constant value or click the Ellipsis button  to use the Reference Select dialog box to select a field reference.

Ignoring a Lookup

Fields View

A ManuScript can include a decision to ignore a lookup. The lookup may not be pertinent in some situations and you may wish to use a value other than the lookup value.

When you select the Ignore lookup when check box, the ManuScript checks a condition before processing the lookup and then determines whether to use the value of the lookup or another value.

To limit when a lookup is performed:

  1. Select the Ignore lookup when check box.
  2. Click CB to use the Condition Builder dialog box to specify the conditions under which the lookup should be ignored.
  3. In the set the value to text box, enter the value to be used when the condition is met.

    You can enter a constant value or click the Ellipsis button  to use the Reference Select dialog box to select a field reference.
