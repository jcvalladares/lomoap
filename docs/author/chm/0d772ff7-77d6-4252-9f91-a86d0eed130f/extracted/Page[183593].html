Benefits of Inheritance

Save Page to .PDF

Inheritance brings many benefits to the EXAMPLE Platform®, but the primary benefit is reusability. Once a ManuScript is developed and tested, you can inherit that ManuScript and apply only the changes necessary to extend or customize its logic. The following sections summarize the benefits gained by using ManuScript inheritance.

ManuScript Reuse

The content of a base ManuScript is automatically available to any derived ManuScript. This reuse of content applies to the initial creation of a ManuScript, but it also applies to alterations (or bug fixes) to the base ManuScript. All changes made to a base ManuScript are immediately propagated to derived ManuScripts when the base ManuScript is deployed as long as the updated fields have not been overridden in the derived ManuScripts.

Simple Adoption of Upgrades and New Versions

When an EXAMPLE ManuScript™ is derived from a base ManuScript, the derived ManuScript must be able to accommodate the frequent release of new base ManuScript versions. With inheritance, the adoption of new base versions is very simple. To adopt the new version of a base ManuScript into a derived ManuScript, the user can simply make a new version of the derived ManuScript and change the inherited ManuScript association to the new version of the base ManuScript. The new features and behavior of the revised base will then be instantly available to the derived ManuScript. The system preserves override features created previously in the derived ManuScript.

Use, Is, Contains Relationships

Prior to inheritance, only two options for using previously built items existed: importing and external reference. External reference uses a use relationship, where the items in external ManuScripts execute at runtime. Importing uses a contains relationship, bringing items from an outside ManuScript into the active ManuScript. With inheritance, however, the is relationship can now be used. A derived ManuScript is its base ManuScript. Inheritance also brings additional power to the contains relationship: once logic exists in a base ManuScript, it is immediately usable in all derived ManuScripts with only one source code to maintain.

Separation of Purpose

In the inheritance model, you can set up base behaviors and inherit separate base ManuScripts for specific purposes. For example, you can inherit a base ManuScript to define the fields, rating, and rules around a product. You can then inherit separate base ManuScripts for page design information and forms work. Both of these specific-purpose ManuScripts can be managed separately, yet both share the rules and definitions inherited from the main data, rates, and rules ManuScript.
