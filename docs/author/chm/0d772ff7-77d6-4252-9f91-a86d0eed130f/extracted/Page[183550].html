Custom Parameters Supported by Grid Widgets

Save Page to .PDF

You can add custom parameters to fields used on grids in EXAMPLE Express®. The following table displays the custom parameters currently supported by grid widgets.

Parameter

Description

customWidth

Sets the width of a column within a grid in EXAMPLE Express®. If the sum of the widths of each column is greater then the total width of the grid, individual column width will be determined by the ratio of the current column width to the sum of the column widths. Using this parameter also allows you to use percentages to determine column width.

When a custom parameter from a Version 1 page is added as a custom property to a Version 2 page during conversion, you should evaluate whether any of the standard properties for Version 2 pages already accomplish what is specified in the custom property. If the standard properties do not accomplish what is needed, you must customize your skin to accommodate the custom property. For more information about converting custom parameters, see Conversion Support for Custom Parameters.
