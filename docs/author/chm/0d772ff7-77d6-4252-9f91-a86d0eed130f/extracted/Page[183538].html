You can add or remove pages, convert pages from version 1 to version 2, and define page properties.

Adding a Page

 Page Designer View

To add a version 2 page:

  1. Click the PageSet under which to add a page.
  2. Click the Add Page button .

    The Add Page dialog box appears.

  3. In the Page Version list, click 2.0.
  4. (Optional) If the page is a meta page, select the Meta Page check box.

    Meta pages are processed after other Page Designer pages.

  5. Enter the name of the new page.

    The <header> option valid for version 1 pages is not valid for version 2 pages. To create a header page in version 2 pages, select the Meta Page check box for the desired page (Step 4, above), and then define the Position property for the page as desired.

  6. (Optional) Select the Referenced Page check box.
    1. To the right of the ManuScript text box, click the Ellipsis button  to use the Reference Select dialog box to select a field.

      The ManuScript defaults to the current ManuScript.

    2. Select the appropriate PageSet and Page:
      • If the ManuScript is the current ManuScript — Click the PageSet and page to reference.
      • If the ManuScript is specified — Click the Ellipsis button  to use the Reference Select dialog box to select a field containing the name of the PageSet and page to reference.
  7. Click OK.

    The Select Group Association dialog box appears.

  8. Click the group to use for the page, and then click OK.

    The system adds the group and a corresponding section.

Deleting a Page

 Page Designer View

To delete a page:

  1. Click the page you wish to delete.
  2. Click the Delete button .
  3. In the Confirm dialog box, click Yes to confirm the deletion or No to cancel.

Defining Page Properties

 Page Designer View

To define a page, specify the following properties.

Property

Description

Basic

Page Name

Name of the page.

Page Version

Version of the page.

ManuScript Reference (referenced pages only)

Specification of the ManuScript containing the referenced page. (If blank, this property defaults to the current ManuScript.)

Page Set Reference (referenced pages only)

Specification of the PageSet containing the referenced page.

Page Reference (referenced pages only)

Specification of the referenced page.

Caption

Name of the page as the user sees it.

Position (meta pages only)

Specification of where the meta page content should appear. This property appears only for pages designated as meta pages.

Show Page

Indication of whether the page should be visible.

Read-Only Content

Indication of whether the page is read-only. This page-level property overrides the field-level Read Only property.

Execute ManuScript

Indication of whether the ManuScript calculates values before the page is displayed. Options are:

  • No — Do not execute the ManuScript.
  • Calculate — Calculate the field specified as the primary value and display the result, but do not update the session.
  • Calculate and Accept — Calculate the field specified as the primary value and display the result, and update the session.

Execute Field

Indication of the field to execute. This property appears only when the Execute Manuscript property is set to Calculate or Calculate and Accept.

Allow Calculation

Boolean value that specifies whether or not to run Calculate or Calculate and Accept for a specified field. This property appears only when Execute Manuscript is set to Calculate or Calculate and Accept.

Include Worksheet Data

Indication of whether to enable rating worksheet functionality on the page. This property appears only when the Execute ManuScript property is set to Calculate or Calculate and Accept.

Include Debug

Boolean value that specifies whether the page response should include rating debug information.

Advanced

Hide Header

Indication of whether the meta page should display on this page.

Hide Annotations

Indication of whether annotation links should display on this page.

Show Rating Messages

Indication of whether rating messages should display on this page.

Display As Popup

Indication of whether to display the page as a pop-up, with the appropriate buttons and pop-up window elements.

Navigation Class

Indication of the navigation class to associate with the page. The referenced field must return one of the following values:

  • Complete — All required fields on the page are complete.
  • Incomplete — Required fields on the page are not complete.
  • Caution — All required fields on the page are complete, but verification is recommended before proceeding.

Depending upon skin customizations, other values may be valid for this property.

Hover Help

Indication to display annotations when the cursor hovers over a field instead of linking the field caption to the annotation.

Next Button Caption

Caption to replace "Next" on the Next button. Entering "" prevents the button from displaying.
Next Button Type

Type of custom button to be used for the Next button. If left blank, the green Avant Garde button type will be used.

The Next Button Type property must be set for each page whose Next button you wish to customize.

Previous Button Caption

Caption to replace "Previous" on the Previous button. Entering "" prevents the button from displaying.
Previous Button Type

Type of custom button to be used for the Previous button. If left blank, the green Avant Garde button type will be used.

The Previous Button Type property must be set for each page whose Previous button you wish to customize.

Style

Page Style

CSS styles to apply to the page content. Styles apply according to CSS inheritance rules.

You can also add annotations to pages.

Setting the Page Name

 Page Designer View

The Page Name property specifies the name of the page as the user sees it. The value of this property is set in the Add Page dialog box when you create the page.

To change the name of a page:

  1. Right-click the page.
  2. In the shortcut menu, click Rename.

    The Rename Item dialog box appears.

  3. Enter the new name for the page, and then click OK.

    The Page name changes in the Page Designer list and in the Page Name property.

Setting the Page Version

The Page Version property specifies the page version. The value of this property is set in the Add Page dialog box when you create the page. If you have defined the page version as version 1, you can convert the page to version 2.

Pages cannot be converted from version 2 to version 1.

To convert a page to version 2:

  1. On the Tools menu, click Page Converter.

    The Page Converter dialog box appears.

  2. Click Convert a single page, and then specify the PageSet and Page you wish to convert.
  3. Click Continue.

    A warning message appears.

  4. Select Yes, I understand, and then click Continue.
  5. In the success confirmation dialog, click OK.

    The Page version changes in the Page Version property.

Setting the ManuScript Reference Property (Referenced Pages)

 Page Designer View

The ManuScript Reference property appears only for referenced pages. The ManuScript Reference property specifies the ManuScript containing the page to reference. If blank, this property defaults to the current ManuScript. The value of this property is set in the Add Page dialog box when you create the page.

To change the ManuScript Reference property:

  1. Click the referenced page.
  2. On the Definition tab, click ManuScript Reference.
  3. To the right of the ManuScript Reference text box, click the Ellipsis button  to open the Edit Reference Page dialog and change the ManuScript, PageSet, or Page.

Setting the Execute ManuScript Property

 Page Designer View

The Execute ManuScript property specifies whether the ManuScript calculates values before the page is displayed.

To set the value of the Execute ManuScript property:

  1. Click the page.
  2. On the Definition tab, click Execute ManuScript.
  3. In the Execute ManuScript list, click the appropriate option:
    • No — Do not execute the ManuScript.
    • Calculate — Calculate the field specified as the primary value and display the result, but do not update the session.
    • Calculate and Accept — Calculate the field specified as the primary value and display the result, and update the session.

Executing a ManuScript often slows performance. Only execute when necessary.

Setting Page Annotations

 Page Designer View

An annotation may be added to any field, page, section, table, or grid widget. Annotations can contain any text, but they are generally used to display descriptive information as help text for a product user interface.

To set the value of the Annotations property:

  1. Click the page.
  2. On the Definition tab, click Annotations.

    The Annotation and Topics dialog box appears.

  3. Enter an annotation for the page, and then click OK.

For more information, see Setting Field Annotations.
