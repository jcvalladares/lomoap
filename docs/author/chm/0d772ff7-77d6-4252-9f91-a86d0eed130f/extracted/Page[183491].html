With a Select value type, you determine a value from a selection list. The Select type is best used when the key selection field has a list of options, but can be used with any field that has a predictable value.

Defining a Select Value

Fields View

To define a Select value:

  1. In the dropdown list for the appropriate property, click Select.
  2. To the right of the Select on text box, click the Ellipsis button to use the Reference Select dialog box to choose a field from which to select.

    The Code Select dialog box appears with a list of the codes, if any, for the selected field.

  3. Use the Code Select dialog to select the cases to be matched for the Case column.
    1. Click a code or codes in the Available codes.
    2. Use the arrow buttons to move the codes for the left column (existing) into the right column (used).

      You can use the arrows to move codes between boxes in both directions.

    You can also enter values directly in the Case column.

  4. Enter values in the Value column.

    These values are used if the associated cases are matched.

    You can enter a constant value or click the Ellipsis button  to use the Reference Select dialog box to select a field reference.

  5. Enter a value in the If no match above, use this value text box.

    This value is used if no match is found to any of the specified cases.

    You can enter a constant value or click the Ellipsis button  to use the Reference Select dialog box to select a field reference.

The Auto-Fill button can also be used to open the Code Select dialog box to make changes to the Case column.
