Setting Field Maximums

Fields View

The Maximum value is the largest value the field may have.

To set the value of the Maximum property:

  1. Click the field.
  2. In the Maximum list, click the appropriate value type.

    The Maximum property is most often defined as a Constant/Field value type.

    For more information, see Defining Property Value Types.

  3. Complete the Definition pane for the value type.
