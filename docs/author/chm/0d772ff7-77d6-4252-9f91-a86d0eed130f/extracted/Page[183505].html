Setting Field Minimums

Fields View

The Minimum value is the smallest value allowed for the field.

To set the value of the Minimum property:

  1. Click the field.
  2. In the Minimum list, click the appropriate value type.

    The Minimum property is most often defined as a Constant/Field value type. For more information, see Defining Property Value Types.

  3. Complete the Definition pane for the value type.
