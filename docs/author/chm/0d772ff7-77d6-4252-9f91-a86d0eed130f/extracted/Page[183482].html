Conditional

Save Page to .PDF

With a Conditional value type, you define a condition that determines a true or false value.

Conditions can be added to conditional tables, conditional fields, and to Miscellaneous Rules for fields and in other places where a condition is needed. When using the Condition Builder dialog box you can add, delete, group, ungroup, edit, and change the order of conditions.

Defining a Condition

Fields View

To define a Condition value:

  1. In the list for the appropriate property, click Condition.

    You can enter the condition directly into the condition window, but it is best practice to use the Condition Builder.

  2. Click Condition Builder.

    The Condition Builder dialog box appears with the Reference Select dialog box over it.

  3. Specify each phrase of the condition:

    For each condition, you identify two references to be compared and the method of comparison. To use multiple conditions, connect the conditions with And or Or connectors.

    1. Enter the first Reference.

      You can enter a constant value or click the Ellipsis button  to use the Reference Select dialog box to select a field reference.

    2. In the Comparison list, click the appropriate item.

      The available comparisons are =, <, >, <=, >=, <>, Is, IsNot, and Contains.

    3. Enter the second Reference.

      You can enter a constant value or click the Ellipsis button  to use the Reference Select dialog box to select a field reference.

    4. (Optional) In the Connector list, click And or Or to add another phrase.
  4. (Optional) Highlight phrases to be grouped in the condition, and then click the Group button .
  5. In the Boolean Result list, click the desired result.

    Options are:

    • Just return TRUE or FALSE
    • Return the specified value for TRUE, nothing for FALSE
    • Return the specified value for TRUE or FALSE
  6. If you specified a Boolean Result using specified values, enter the TRUE Value and FALSE Value to be used as appropriate.

    You can enter a constant value or click the Ellipsis button  to use the Reference Select dialog box to select a field reference.

Adding a Condition Phrase

Fields View

To add a condition phrase:

  1. Click the line above the line on which you wish the new phrase to appear.
  2. Click the Add Phrase button .
  3. Define the condition phrase.
Deleting a Condition Phrase

Fields View

To delete a condition phrase:

  1. Click the condition phrase.
  2. Click the Delete Phrase button .
Grouping and Ungrouping Condition Phrases

Fields View

To make sure that the certain condition phrases are carried out in the correct logical sequence, groupings can be added or removed to isolate logical conditions.

To group and ungroup condition phrases:

  • Select the appropriate condition phrases.
    • Click the Group Phrases button  to group the selected condition phrases.
    • Click the Ungroup Phrases button  to remove the grouping.
    • Click the Ungroup All  button to clear all groupings in the current condition.
Moving Condition Phrases

Fields View

To move condition phrases up or down:

  1. Click the condition phrase to move within the Condition Builder.
  2. Click the Move Up button  or the Move Down button  to move the condition phrase.
