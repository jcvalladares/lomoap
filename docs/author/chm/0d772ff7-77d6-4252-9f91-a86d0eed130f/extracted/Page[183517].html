Setting the Required Property

Fields View

Any public field or group can be set to Required.

To set the value of the Required property:

  1. Click the field or group.
  2. On the Definition tab, in the Required list, click the appropriate value type. For more information, see Defining Property Value Types.
  3. Complete the definition pane for the value type.

    The result must be either 1 (for true) if the field is required, or 0 (for false) if the field is not required.

    You can enter a constant value or click the Ellipsis button  to use the Reference Select dialog box to select a field reference.
