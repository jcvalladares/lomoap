 Fields View

Visibility in ManuScripts is a means to hide those groups and fields that are used only for organization or processing within a ManuScript. Fields and groups set to Private will not appear in the XML output of a ManuScript. Public fields can be included in private groups.

Private groups are useful for organization within a ManuScript.

Private fields contain calculations, conditions, or other processing functions that are used only within a given ManuScript or its derived ManuScripts.

Fields must be public if they are:
  • Iterated
  • A table in a shredded database
  • Required by a data schema
  • Included in output XML
  • Fed into any downstream system
  • Included on an EXAMPLE Express® or other HTML page
  • A column in a shredded database
  • Required by a data schema
  • Included in output XML
  • Fed into any downstream system
  • Included in a report generated from a shredded database
