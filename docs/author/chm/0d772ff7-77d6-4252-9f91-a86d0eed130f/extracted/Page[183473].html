Identifying Where a Field or Group Is Used

Save Page to .PDF

 Fields View

You can see all the places a field, group, or table is used with the Used by function. This function identifies the other fields in the ManuScript that use the selected item.

To identify other fields that use the selected item:

  • On the Edit menu, click Used by.

    You can also:
    • Press CTRL+U
    • Right-click the field, and then click Used by.

Before you modify a field, check where that field is used to determine how the change might affect previously coded fields. Note that the Used by function does not display the use of a field in external ManuScripts.
