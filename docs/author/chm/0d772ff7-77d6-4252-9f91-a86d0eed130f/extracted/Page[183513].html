Setting Field Captions

Fields View

The Caption property specifies the name of the field as the user sees it.

To set the value of the Caption property:

  1. Click the field or group.
  2. On the Definition tab, in the Caption list, click the appropriate value type.

    Captions are typically a Constant/Field value type. For more information, see Defining Property Value Types.

  3. Complete the Definition pane for the value type.
