Sum Accumulator

Save Page to .PDF

With a Sum/Accumulator value type, the returned value is based on the iterations of a group in a ManuScript when called from an Iterator field. Sum/Accumulator fields increase the efficiency of a ManuScript for large iterations. 

For example, a ManuScript with two Iterator fields loops through the iterative group two complete times.  You can use a single Iterator to increase efficiency.  If you create two Sum/Accumulator fields in the place of the two Iterator fields, and one Iterator field that references the two Sum/Accumulator fields, the iterative groups only loop once for the number of instances of the iterative group.  As the Iterator processes through each group, it performs the selected function for the fields that the Sum/Accumulator fields reference.  When a complete loop is finished, each Sum/Accumulator field holds the calculated value. 

You do not have to specifically reference the Iterator group.  When a Sum/Accumulator field is referenced and the Iterator has not yet processed, the Iterator executes and gets values for each Sum/Accumulator field.

Defining a Sum/Accumulator Value

Fields View

To define a Sum/Accumulator value:

  1. In the dropdown list for the appropriate property, click Sum/Accumulator.
  2. Click the Ellipsis button to the right of Field to access for each iteration's value to use theReference Select dialog box to select a field reference.

    This is the value on which the iterator operates.

  3. Click the Ellipsis button to the right of Iterator field that evaluates the Iterator item to use the Reference Select dialog box to select a field reference.

    This is the field that defines and controls the iteration.
