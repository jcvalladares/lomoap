Database Mapping

Save Page to .PDF

You use the Database Mapping tool to specify which fields in the ManuScript to store as fields in the database. The entire ManuScript is stored in the database, but the data is stored as one large group, which makes it difficult to access specific data items. By storing the data as fields, you may access the data with any standard database access tool.

The fields you store may be required or optional fields in the ManuScript. Public fields in the Database Mapping are not executed at save time in EXAMPLE Express®. Private fields in the Database Mapping must be executed at save time because the value of a private field must be executed to be determined.

Because the Database Mapping contains private and public fields, the ManuScript can determine if rules are performed only at save time or if they are always run by the system. If the rules are to be run at save time, use a private field that references the fields or rules to be executed. If the XML data is to be extracted as is, use a public field in the Database Mapping.

To open the Database Mapping tool:

  • On the Tools menu, click Database Mapping.

    The Database Mapping dialog box appears.

Mapping Required Fields

There are 18 required fields already defined in the database. You must map a ManuScript field to each of these fields. You can also define and map to optional fields if you wish to store additional data.

To map the required fields:

  1. In the Database Mapping dialog box, click the line in the Data Name list.
  2. Click the Ellipsis button to the right of the Field text box to use the Reference Select dialog box to select the appropriate field.
  3. Repeat steps two and three for all of the required fields.

Mapping Optional Fields

In addition to the 18 required fields that you must map in your ManuScript, you can also map optional fields.

To map optional fields:

  1. In the Database Mapping tool, click the first empty row in the Optional Fields grid.
  2. Enter an appropriate Data Name.
  3. Click the Ellipsis button to the right of the Field text box to use the Reference Select dialog box to select the appropriate field.
  4. Repeat steps one through three to add each optional field.
Inserting an Optional Field

To insert an Optional Field:

  1. In the Database Mapping tool, click the row in the Optional Fields grid above which to insert the Field.
  2. Click Insert Item.

    The line you selected is moved down, creating room for another entry.

  3. Enter an appropriate Data Name.
  4. Click the Ellipsis button to the right of the Field text box and then use the Reference Select dialog box to select the appropriate field.
  5. Repeat steps one through four for each field to insert.
Deleting an Optional Field

To delete an Optional Field:

  1. In the Database Mapping tool, click the row in the Optional Fields grid to delete.
  2. Click Delete Item.

Removing All Mapped Fields

You can remove all the mapped fields with the Database Mapping tool.

This removes the mapping for both the required and the optional Fields.

To remove all mapped fields:

  1. In the Database Mapping tool, click Remove All.

    The Confirm dialog box appears.

  2. Click Yes to remove all the mappings or No to cancel the process.
