Fields View

Save Section to .PDF Save Page to .PDF

The development of a ManuScript involves defining how each field gets its value and the rules each field processes. You use groups in the ManuScript to organize fields and sub-groups into a logical collection. Fields contain the power of computation and rules execution.

The Fields view is the listing of groups and fields in the ManuScript. It allows you to edit the details for each group or field.

To open the Fields view:

  • Click the Fields button .

    You can also:
    On the View menu, click Fields.
