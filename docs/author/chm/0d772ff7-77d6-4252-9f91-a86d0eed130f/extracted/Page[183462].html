Best Practices for ManuScript Development

Save Page to .PDF

The following are recommended best practices for ManuScript development:

  • Leave the default of data for the root group in a new ManuScript.
  • Save the ManuScript often. There is no autosave feature in EXAMPLE Author®.
  • Add the following three private groups under every public group: GroupNameInput, GroupNameOutput, and GroupNamePrivate (AccountInput, AccountOutput, and AccountPrivate, for example).
  • Always select the Prepend group name to field check box when creating a field.
  • Before you modify a field, check where that field is used to determine how the change might affect previously coded fields. Note that the Used by function does not display the use of a field in external ManuScripts.
  • There are many places where you can either enter a value manually or let the program look it up for you. To ensure that the value is entered correctly, do not manually enter field names. To avoid errors, always select fields using the Ellipsis button  rather than manually entering field names.
  • Many tables have a large number of entries. Avoid entering large amounts of table data if there is already an electronic list of the items. Instead, copy and paste from the electronic version of the list.
  • Assign all fields when mapping to the EXAMPLEData Database.

  • Do not change the versionID of a versioned ManuScript. The versionID links all the versions of a ManuScript together and should never be modified for versioned ManuScripts.

For more information about best practices for ManuScript development, contact your Professional Services representative or Account Manager.
