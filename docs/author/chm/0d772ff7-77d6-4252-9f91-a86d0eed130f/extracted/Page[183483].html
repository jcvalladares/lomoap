With a Constant/Field value type, you assign the value as a constant value or as the value of a referenced field.

Defining a Constant Value

Fields View

To define a Constant value:

  1. In the dropdown list for the appropriate property, click Constant/Field.
  2. To the right of the Constant/Field Value column, click the Ellipsis button  to open the Reference Select dialog box.
  3. In the Field or Value area, click Value.
  4. Enter the constant value.
  5. Click OK.
Defining a Constant Value Using Selected Codes

Fields View

If you define an option list for a field, you can define a constant value from the option list for the field.

To define a Constant value using selected codes:

  1. In the dropdown list for the appropriate property, click Constant/Field.
  2. To the right of the Constant/Field Value column, click the Ellipsis button  to open the Reference Select dialog box.
  3. In the Field or Value area, click Value.
  4. Click a field with a defined Options property, and then click SC.

    The Code Select dialog box appears.

  5. Use the arrow buttons to move codes from the Available Codes list to the Used Codes list.
  6. Click OK.

    The codes are placed in the Value text box.

  7. Click OK.
Defining a Field Reference Value

Fields View

To define a Field Reference value:

  1. In the dropdown list for the appropriate property, click Constant/Field.
  2. To the right of the Constant/Field Value column, click the Ellipsis button  to open the Reference Select dialog box.
  3. In the Field or Value area, click Field Reference.
  4. Click the appropriate field.
  5. Click OK.
