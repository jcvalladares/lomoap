Sections

Save Section to .PDF Save Page to .PDF

Sections are parts of a page used as containers for fields, actions, tables, widgets, or other sections. You can add, duplicate, and remove sections, as well as define section properties and convert sections to tables or grids widgets. Sections can be nested within other sections or within tables.

Sections should not be used to display iterative data. When displaying iterative data, use tables or grid widgets.

Adding a Section

Page Designer View

To add a section:

  1. Click the section or table under which to add another section.
  2. On the Edit menu, click Add Section.

    You can also:
    Right-click a section or table, and then click Add Section.

Duplicating a Section

Page Designer View

To duplicate a section:

  1. Click the section you wish to duplicate.
  2. On the Edit menu, click Duplicate.

    You can also:
    Right-click the section, and then click Duplicate.

    The Duplicate Section dialog box appears.

  3. Click the type of action to take. Options are:
    • Duplicate section structure only
    • Duplicate section structure and fields
    • Duplicate section structure and replace fields
  4. If you choose to duplicate the section structure and replace fields, define Field Replacement Rules.
    1. Click a group for Replace fields from the group.
    2. Click a group for With similar field in the group.
  5. Click OK.

Deleting a Section

Page Designer View

To delete a section:

  1. Select the section you wish to delete.
  2. Click the Delete button .
  3. In the Confirm dialog box, click Yes to confirm the deletion, or No to cancel.

Converting a Section

For instructions on converting a section to a table or grid widget, see Converting Sections.

Defining Section Properties

Page Designer View

To define a section, specify the following properties.

Property

Description

General

Section Caption

Text to describe the section.

Layout Direction

Direction the section content is laid out on the page.

Field Caption Position

Specification of where to display field captions. Options vary depending upon the Layout Direction and Field Caption Display selected.

Field Caption Display

Specification of when to display field captions.

Show Condition

Specification of when to display the section.

Read-Only Content

Specification of whether section content should be read-only.

Advanced

Collapsible

Indication of whether the section is collapsible. When True, additional properties appear:

  • Start Closed — Indicates whether to default the section to closed. (True/False)
  • Toggle Bar Caption — Specifies the caption for the toggle bar. If blank, the system uses the section caption.

Expand Event

Specification of a field to execute when the section is expanded. This property is only applicable when the section is in an accordion section.
Static Content Type

Specification of the method to use for embedding external content in EXAMPLE Express®. Options include:

  • HTML
  • iFrame

Sub-parameters:

  • Content URL – Indicates the URL where the external content you wish to embed resides.
  • Content Title – Indicates whether a title bar containing the specified string will appear in the title bar at the top of the panel.
  • Content Border – Indicates whether to display or hide the border.
  • Content Frame – Indicates whether to display or hide the frame.
  • Content Collapsible – Indicates whether the content should be collabsible.
  • Content Scrollable – Indicates whether the content should be scrollable.
  • Content Height – Indicates the desired height of the panel.
  • Content Name – Applies a name to an iFrame, if applicable.

Display

Section Style

CSS styles to apply to the section content. Styles apply according to CSS inheritance rules.

Section Caption Style

CSS styles to apply to the section caption. Styles apply according to CSS inheritance rules.

Field Caption Style

CSS styles to apply to the captions of fields in the section. Styles do not apply to fields in child sections, tables, or grid widgets. Styles apply according to CSS inheritance rules.

Field Style

CSS styles to apply to read-only fields in the section. Styles do not apply to fields in child sections, tables, or grid widgets. Styles apply according to CSS inheritance rules.

Action Style

CSS styles to apply to the actions in the section. Styles do not apply to actions in child sections, tables, or grid widgets. Styles apply according to CSS inheritance rules.
Custom Container

Custom style to apply to a container.

 

Sub-parameters:

  • panelHeader – Custom parameter that creates a title for a custom container.
  • alignHeader – Custom parameter that center or right-aligns a container title. If not specified, the container aligns to the left.
Icon Image Allows an icon to be placed in the section heading.

Icons only appear if an associated section caption is present.

In addition to defining the above properties, you can also define annotations for sections, and you can add actions to sections. For information on adding actions, see Actions.

Setting the Section Caption Property

Page Designer View

The Section Caption property contains text to describe the section.

To set the value of the Section Caption property:

  1. Click the section.
  2. On the Definition tab, click Section Caption.
  3. Enter the section caption.

    The caption is added to the selected section in the Page Designer list.

Setting the Layout Direction Property

Page Designer View

The Layout Direction property specifies the direction the section content is laid out on the page. The direction can be Across or Down.

To set the value of the Layout Direction property:

  1. Click the section.
  2. On the Definition tab, click Layout Direction.
  3. In the Layout Direction list, click Down or Across.
Setting the Field Caption Position Property

Page Designer View

The Field Caption Position property specifies where to display field captions. The options for this property vary depending upon the Layout Direction and Field Caption Display selected.

To set the value of the Field Caption Position property:

  1. Click the section.
  2. On the Definition tab, click Field Caption Position.
  3. In the Field Caption Position list, click Before Field or Above Field.
Setting the Field Caption Display Property

Page Designer View

The Field Caption Display property specifies when to display field captions.

To set the value of the Field Caption Display property:

  1. Click the section.
  2. On the Definition tab, click Field Caption Display.
  3. In the Field Caption Display list, click the appropriate option. The Field Caption Display property includes the following options.

    Option

    Description

    All

    Displays captions.

    None

    Does not display captions.

    Only Captions

    Does not display the field values, just the captions of the fields.
Setting the Show Condition Property

Page Designer View

The Show Condition property specifies when to show the section.

To set the value of the Show Condition property:

  1. Click the section.
  2. On the Definition tab, click Show Condition.
  3. To the right of the Show Condition text box, click the Ellipsis button  to use the Reference Select dialog box to select a boolean field.
Setting the Read-Only Content Property

Page Designer View

The Read-Only Content property specifies whether the section is read-only.

To set the value of the Read-Only Content property:

  1. Click the section.
  2. On the Definition tab, click Read-Only Content.
  3. In the Read-Only Content list, click False or True.
Setting the Collapsible Property

Page Designer View

The Collapsible property specifies whether the section is collapsible. When True, the Start Closed and Toggle Bar Caption properties appear.

To set the value of the Collapsible property:

  1. Click the section.
  2. On the Definition tab, click Collapsible.
  3. In the Collapsible list, click True or False.
Setting the Start Closed Property

Page Designer View

The Start Closed property appears when the Collapsible property is set to True. The Start Closed property indicates whether to default the section to closed.

To set the value of the Start Closed property:

  1. Click the section.
  2. On the Definition tab, beneath the Collapsible property, click Start Closed.
  3. In the Start Closed list, click True or False.
Setting the Toggle Bar Caption Property

Page Designer View

The Toggle Bar Caption property appears when the Collapsible property is set to True. The Toggle Bar Caption property specifies the caption for the section toggle bar. If this property is blank, the system uses the section caption as the toggle bar caption.

To set the value of the Toggle Bar Caption property:

  1. Click the section.
  2. On the Definition tab, beneath the Collapsible property, click Toggle Bar Caption.
  3. Specify a value, or, to the right of the Toggle Bar Caption text box, click the Ellipsis button  to use the Reference Select dialog box to select a boolean field.

Setting the Custom Container Property

Page Designer View

The Custom Container property specifies the custom style to apply to a container.

To set the value of the Custom Container property:      

  1. Click the section.
  2. On the Definition tab, beneath Display, click Custom Container.
  3. Click the Ellipsis button  to use the Reference Select dialog box to select a field.

By default, custom containers are as wide as their parent container. To create a narrower container, place the section with the custom container inside a parent container that has a defined width.

Setting Section Annotations

Page Designer View

An annotation may be added to any field, page, section, table, or grid widget. Annotations can contain any text, but they are generally used to display descriptive information as help text for a product user interface.

To set the value of the Annotations property:

  1. Click the section.
  2. On the Definition tab, click Annotations.

    The Annotation and Topics dialog box appears.

  3. Enter an annotation for the section, and then click OK.

For more information, see Setting Field Annotations.
