Page Designer

Save Section to .PDF Save Page to .PDF

You use Page Designer to define the layout of input screens and documentation. Each page designed in Page Designer can be accessed through calls to the EXAMPLE Server® to:

  • Use in an interview process
  • Render documentation about the ManuScript

Page Designer defines the information necessary to convert ManuScripts into a series of interview Web pages.

When creating pages in Page Designer, you can build them as Version 1 pages or as Version 2 pages. The page version you choose depends upon the skin that will render the pages in EXAMPLE Express®. When rendering pages in skins based on Duck Creek Technologies, Inc. DemoNational, you must use Version 1 pages. When rendering pages in skins based on the Next Generation Web Design, you can use Version 1 or Version 2 pages (Version 2 pages are recommended). You can convert Version 1 pages to Version 2 pages at any time using EXAMPLE Author®'s Page Converter tool. The conversion process, however, is a one-way process.

To open the Page Designer view:

  • Click the Page Designer button .

    You can also:
    On the View menu, click Page Designer.

When you double-click a field in Page Designer, the Fields view opens with that field selected.
