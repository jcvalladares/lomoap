Page Designer View

You can view the ManuScript inheritance chain for pages in the current ManuScript in the Inheritance dialog box. The Inheritance (Pages) dialog box displays the entire ManuScript inheritance chain for the current ManuScript's pages. From this dialog box, you can open any ManuScript in the inheritance chain by selecting the desired ManuScript and clicking Go to.

To access the Inheritance (Pages) dialog box:

  • On the View menu, point to Inheritance, and then click Pages.

    You can also:
    On the shortcut menu for Page Designer, click View Inheritance (Pages).
