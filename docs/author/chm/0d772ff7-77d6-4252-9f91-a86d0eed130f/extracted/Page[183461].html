EXAMPLE Author® defines all features of an insurance product: rates, rules, algorithms, documentation, screen flow, and policy transactions. In EXAMPLE Author®, you create, edit, and test ManuScripts, XML files used to describe products, and define how those products process the rules and values of data.

The EXAMPLE Author® User Interface

The EXAMPLE Author® application is divided into several main views:

  • Fields – Defines fields, groups, and their relationships.
  • Tables – Defines data tables.
  • Page Designer – Creates and edits input screens.
  • Data Tester – Tests the execution of the ManuScript and creates and edits data documents associated with the active ManuScript.
  • Forms Mapper – Creates and edits forms.

Logging in to EXAMPLE Author®

You use the Login dialog to identify yourself as the user and to select an EXAMPLE Server® connection.

To login to EXAMPLE Author®:

  1. On the Windows Start menu, in the All Programs list, point to Duck Creek Technologies, point to Author, and then click Author.

    The Login dialog box appears.

    If you are already in EXAMPLE Author® and wish to change your server or user name, on the File menu, click Login User/Server.

  2. Enter your user name.
  3. In the Server list, click the appropriate EXAMPLE Server®, or click (work locally) to work in standalone mode.
  4. Enter your password.
  5. Click OK.

    The Open/New ManuScript dialog box appears.

Working in Enterprise Mode

You use Enterprise Mode when you work on a ManuScript stored on an EXAMPLE Server®. You can also work in Enterprise Mode locally by setting up your local installation as an EXAMPLE Server®. If you log in to an EXAMPLE Server®, you are automatically placed in Enterprise Mode.

When you work in Enterprise Mode:

  • You are prompted to confirm any change you make.
  • If revision tracking has been enabled, you must enter a comment about your changes.
Setting Directories Options

Click the Directories tab in the Options dialog box to define where the Catalog and schema files reside for local usage of EXAMPLE Author®. The directories, except the EnterpriseFormsRootPath, are pre-set during installation. They can be modified for custom use.

You can modify the directory file locations for the following files:

  • Catalog — Location of ManuScript and data files Catalogs and directories.
  • Debug — Location of the .tsv debug folder.
  • Forms — Location of forms for the preview (Enterprise mode). This is the initial search point for forms. The path should be where the form files are created by default.
  • Preview — .Xsl files that define the preview.
  • Schema — Location of data schemas.

You can click Restore Default Catalogs to return the settings to the defaults.

Reference Select

You use the Reference Select dialog box in many instances in EXAMPLE Author® to define field references or constant values. The Ellipsis button  generally opens the Reference Select dialog.

To define a constant value:

  1. In the Reference Select dialog, click Value.
  2. In the Value text box, enter the appropriate value.
  3. Click OK.

    You may also use the Code Select dialog box to choose a value defined in the option list of a field. For more information, see Defining a Constant Value Using Selected Codes.

To define a field reference:

  1. In the Reference Select dialog, click Field Reference.
  2. In the list of fields, click the appropriate field.
  3. Click OK.

Searching for Items

You can find items in lists within the Fields, Data Tester, and Forms Mapper views.

To find an item:

  1. Click the Find button  .

    The Search dialog box appears.

    You can also:
    • Press CTRL+F.
    • On the Edit menu, click Find.

  2. Enter the text to find.
  3. Click OK.
  4. If there is more than one instance of the text, click the Find Next button  to find the next instance.

    You can also:
    • Press F3.
    • On the Edit menu, click Find Next.

Inserting Line Breaks

You can insert line breaks in text fields in EXAMPLE Author®.

To insert a line break:

  • Press SHIFT+ENTER.

Security in EXAMPLE Author®

Security in EXAMPLE Author® relies on the roles and privileges assigned through EXAMPLE UserAdmin™ to restrict user access. EXAMPLE Author® is shipped with the System Administrator role assigned, which has no restrictions.

For more information about the security provided through EXAMPLE UserAdmin™, see the EXAMPLE UserAdmin™ Overview or the EXAMPLE UserAdmin™ User Guide.
