 Fields View

You can view the ManuScript inheritance chain for fields and groups in the current ManuScript in the Inheritance dialog box. The Inheritance (Data) dialog box displays the entire ManuScript inheritance chain for the current ManuScript's data (fields and tables). From this dialog box, you can open any ManuScript in the inheritance chain by selecting the desired ManuScript and clicking Go to.

To access the Inheritance (Data) dialog box from Fields view:

  • On the View menu, point to Inheritance, and then click Data.

    You can also:
    On the shortcut menu for Fields View, click View Inheritance (Data).
