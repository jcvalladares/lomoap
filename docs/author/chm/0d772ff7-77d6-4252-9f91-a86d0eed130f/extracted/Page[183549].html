If desired, you can convert a grid widget to a section or a table.

Converting Grid Widgets to Sections

 Page Designer View

You can convert a grid widget to a section at any time. When you convert a grid widget to a section, the system applies all applicable properties defined for the grid widget to the new section as they were defined in the grid widget, with one exception: The Field Caption Display property for the section will be set to All. (The First Iteration option for the Field Caption Display property is not valid for sections.)

To convert a grid widget to a section:

  1. Click the grid widget you wish to convert.
  2. On the Edit menu, click Convert To Section.

    The selected grid widget appears as a section in the Page Designer list.

    You can also:
    Right-click the grid widget, and then click Convert To Section.

Converting Grid Widgets to Tables

 Page Designer View

You can convert a grid widget to a table at any time. When you convert a grid widget to a table, the system applies all applicable properties defined for the grid widget to the new table as they were defined in the grid widget.

To convert a grid widget to a table:

  1. Click the grid widget you wish to convert.
  2. On the Edit menu, click Convert To Table.

    The selected grid widget appears as a table in the Page Designer list.

    You can also:
    Right-click the table, and then click Convert To Table.
