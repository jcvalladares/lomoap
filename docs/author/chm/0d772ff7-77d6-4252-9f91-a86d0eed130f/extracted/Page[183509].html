To add a message when the default is used or the maximum or minimum is reached:

  1. To the right of the property, click the Message button  to open the Message Editor dialog box.
  2. Enter the message.

    If you do not create a message, the system automatically generates a message that indicates that the default, maximum, or minimum value was used. For more information, see Inserting Fields into Annotations and Messages.
