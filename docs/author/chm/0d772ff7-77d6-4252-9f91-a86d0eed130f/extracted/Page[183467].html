ManuScript Properties Dialog Box

The ManuScript Properties dialog box specifies the properties for a ManuScript. It includes two tabs, Standard Properties and Inheritance.

Culture

Culture for this ManuScript.

If a numeric format mask begins with the dollar sign ($), the mask will output with the culture-aware currency symbol, thousands separator, and decimal separator. For example, a mask such as $???,??0.00 will replace the dollar sign ($), the comma (,) and the period (.) with the currency symbol, thousands separator, and decimal separator determined by the ManuScript culture.

Currency

Currency symbol appropriate to the selected culture. This symbol will be included in any Cn format masks, or custom format masks beginning with the dollar sign($), used in the ManuScript.

TRUE=1

When selected, the value for TRUE throughout the ManuScript is 1. If cleared, the value for TRUE is -1.

Field Cache

When this check box is selected, fields are only executed once, unless overridden by the Always Execute Property. Should only be cleared for legacy ManuScript purposes.

Short Circuit Conditionals

Set this property to True to cease processing compound conditionals upon resolution, leaving unneeded conditions unprocessed. True and False override the default setting, defined as the value of the ShortCircuitCond setting in the ManuScript section of the Server.config file.

Clear Iterator Context

Set this property to True to support processing iterators nested under iterators. Enabling this option can slow ManuScript processing. True and False override the default setting, defined as the value of the ClearIterContext setting in the ManuScript section of the Server.config file.

Data Schema

Name of the XML file used for mapping, paths, and other data schema related functions. Click the Ellipsis button to browse to the data schema file location.

Primary Value

Field used as the final result of the ManuScript when the ManuScript is executed. Click the Ellipsis button to use the Reference Select dialog box to select the primary value field.

Contexts

List of current contexts for this ManuScript.

Add

Click to add a new context.

Delete

Click to delete an existing context.

Rename

Click to rename a context.

Release Notes

The list of user-entered notes about the ManuScript.

Changing ManuScript IDs

The ManuScript ID is a number that uniquely identifies each ManuScript to the system.

You should change the ManuScript ID only if you are certain you know the effect of such a change.

To change the ManuScript ID:

  1. On the File menu, click Properties.

    The ManuScript Properties dialog box appears.

  2. On the Standard Properties tab, click Edit ID.

    The Edit ManuScriptID dialog box appears.

  3. In the ManuScriptID text box, enter the new ManuScript ID.

    You should read and pay particular attention to the information shown in the dialog box.

  4. Click OK.

Changing ManuScript Captions

The ManuScript Caption is the name of the file as it is listed in the ManuScript Catalog.

To change the ManuScript Caption:

  1. On the File menu, click Properties.

    The ManuScript Properties dialog box appears.

  2. On the Standard Properties tab, in the Caption text box, enter the new ManuScript Caption.
  3. Click OK.

Changing the Image File Location

The Image File location is the base file name of the image file to be used for rendering presentations.

To edit the Image File location:

  1. On the File menu, click Properties.

    The ManuScript Properties dialog box appears.

  2. On the Standard Properties tab, in the Image file text box, enter the path to the appropriate file.
  3. Click the file, and then click OK.

Changing ManuScript Version Numbers

The Version Number is a reference number that allows you to keep track of the versions of the ManuScript.

To change the Version Number:

  1. On the File menu, click Properties.

    The ManuScript Properties dialog box appears.

  2. On the Standard Properties tab, in the Version text box, enter the new version number.
  3. Click OK.

Changing ManuScript Version Dates

The Version Date is the date of the last revision of this ManuScript.

To edit the Version Date:

  1. On the File menu, click Properties.

    The ManuScript Properties dialog box appears.

  2. On the Standard Properties tab, click Date.

    The Date Selector dialog box appears.

  3. Click the appropriate date in the calendar, or enter the date in YYYY-MM-DD format.
  4. Click OK.

Changing the Data Schema File

To change the Data Schema file:

  1. On the File menu, click Properties.

    The ManuScript Properties dialog box appears.

  2. On the Standard Properties tab, in the Data Schema text box, enter the path to the appropriate file.
  3. Click the file, and then click OK.

Changing the Primary Value

The Primary Value should be the field that holds the final result of the ManuScript.

To change the Primary Value:

  1. On the File menu, click Properties.

    The ManuScript Properties dialog box appears.

  2. On the Standard Properties tab, click the Ellipsis button  to the right of the Primary Value text box.

    The Reference Select dialog box appears.

  3. Click the appropriate field, and then click OK.

Changing the ManuScript Culture

The Culture property determines date and currency formatting in a ManuScript. Note that short date formats are determined by Web browser settings when viewing the ManuScript in EXAMPLE Express®.

To change the Culture:

  1. On the File menu, click Properties.

    The ManuScript Properties dialog box appears.

  2. On the Standard Properties tab, click the appropriate Culture.

    The Currency field changes to display the currency symbol for the selected culture.

Defining Contexts

Contexts specify the type of user accessing the ManuScript in the downstream system or user interface. For instance, an insurance ManuScript may be used by an agent, an underwriter, or a customer. Contexts ensure that users can view only the interface portions required for their parts of the process. An agent may need to see a specific surcharge applied to the customer whereas the customer only needs to see the total policy premium. By adding a context to specific fields, messages, and pages, only those ManuScript viewers logged in under that context see the context-related portions.

You can use contexts directly on annotations, on message text, and in conditionals for many other EXAMPLE Author® elements, such as action buttons on pages, using the current context of the user.

Deleting Contexts

To delete a context:

  1. On the File menu, click ManuScript Properties.

    The ManuScript Properties dialog box appears.

  2. On the Standard Properties tab, in the Contexts area, click the context to delete.
  3. Click Delete.
Adding Contexts

To add a context:

  1. On the File menu, click ManuScript Properties.

    The ManuScript Properties dialog box appears.

  2. On the Standard Properties tab, in the Contexts section, click Add.

    The Add Context dialog box appears.

  3. Enter the context name.
  4. Click OK.
Renaming Contexts

To rename a context:

  1. On the File menu, click ManuScript Properties.

    The ManuScript Properties dialog box appears.

  2. On the Standard Properties tab, in the Contexts area, click the context to rename.
  3. Click Rename.

    The Rename Context dialog box appears.

  4. Enter the new context name.
  5. Click OK.

Adding Release Notes

To add a Release Note:

  1. On the File menu, click ManuScript Properties.

    The ManuScript Properties dialog box appears.

  2. On the Standard Properties tab, in the Release Notes section, click Add New.

    The ManuScript Release Notes dialog box appears.

  3. Enter the release note, and then click OK.
  4. (Optional) Click the Add New button to add additional notes.
