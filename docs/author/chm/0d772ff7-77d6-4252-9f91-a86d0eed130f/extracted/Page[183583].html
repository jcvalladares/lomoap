Portfolio Mapping Wizard

Save Page to .PDF

The Portfolio Mapping tool is an EXAMPLE Author® wizard that allows users to create, modify, or delete mappings that link Portfolio ManuScripts to shared data fields within associated product ManuScripts.

Using the Portfolio Mapping Wizard, Portfolio ManuScript authors can:

  • Select the product ManuScripts that will be associated with the portfolio
  • Link the Portfolio ManuScript "shared data" fields to selected fields within the individual product ManuScripts.

To access the Portfolio Mapping Wizard:

  • From EXAMPLE Author®, in the Fields View, on the Tools menu, click Portfolio Mapping.
    The Portfolio Mapping Wizard opens.

From this screen, users can create a new portfolio mapping or modify an existing one.

Creating a New Portfolio Mapping

The Portfolio Mapping tool enables users to create and define new portfolio mappings through a three-step process:

  1. Create a new mapping.
  2. Select the product ManuScripts that will be included within the portfolio.
  3. Link the Portfolio ManuScript shared-data fields with corresponding fields in the product ManuScripts.
Step One: Create a Portfolio Mapping

The first screen of the Portfolio Mapping Wizard allows users to create and name a new mapping, or to modify or delete an existing mapping.

To create a new Portfolio ManuScript mapping:

  1. From EXAMPLE Author®, with the Portfolio ManuScript open, in the Fields View, on the Tools menu, click Portfolio Mapping.

    The Portfolio Mapping Wizard opens.

  2. Select Create new mapping.
  3. Enter a name or description of the mapping in the Description box, and then click Next to move to the Select ManuScripts page and begin selecting the portfolio products.
Step Two: Select ManuScripts

The second screen of the Portfolio Mapping Wizard allows users to select the product ManuScripts to be included within the Portfolio.

To select portfolio products:

  1. On the Select ManuScripts screen click the Add button .

    The Available Products selection screen appears.

  2. If desired, use the Products Filter to narrow the options in the Available Products list.
  3. In the Available Products list, click the appropriate product ManuScripts, and then click OK.

    The selected product ManuScripts are displayed.

  4. To add additional ManuScripts, click the Add button .
  5. To delete a ManuScript from the list, highlight the product ManuScript name, and then click the Delete button .

    When satisfied with the ManuScript selection, click Next to move to the Map Shared Data Fields page and begin mapping shared data fields.

Step Three: Map Shared Data Fields

The third screen of the Portfolio ManuScript allows users to define shared data for the portfolio. Each field from the sharedData group in the Portfolio ManuScript must be mapped to an appropriate field in each product ManuScript. In addition, each shared data field may be set to be read-only on policy and quote interview screens.

To Map Shared Data fields:

  1. In the first Shared Data field row, click the check box in the Protected column to set the field as read-only on quote and policy interview screens.
  2. In the first product ManuScript column, click the Ellipsis button .

    The Field Selection dialog box appears. The Field Selection dialog box displays groups and fields for the associated product ManuScript.

  3. Select the appropriate ManuScript field or group, and then click OK.
  4. Repeat for each Shared Data field.
  5. Map the remaining Shared Data fields to the first product ManuScript, and then repeat steps 1- 4 for the remaining ManuScripts.
  6. Map all product ManuScripts to the Shared Data fields, and then click Finish.

Modifying a Portfolio Mapping

Portfolio mappings are modified from within the Portfolio Mapping Wizard. From there, users can add or delete associated product ManuScripts and change shared data field associations.

Step One: Modify a Portfolio Mapping

The first screen of the Portfolio Mapping Wizard allows users to create and name a new mapping, or to modify or delete an existing mapping.

To modify a portfolio mapping:

  1. From EXAMPLE Author®, in the Fields View, on the Tools menu, click Portfolio Mapping.

    The Portfolio Mapping Wizard opens.

  2. Click Modify existing mapping, and then select the name of the portfolio mapping to be modified.
  3. Click Next to move to the Select ManuScripts page and modify the list of selected portfolio products.
Step Two: Select ManuScripts

This page displays the currently selected products for the portfolio and allows products to be added or deleted.

To add products to the selected ManuScripts list:

  1. On the Select ManuScripts screen, click the Add button .

    The Available Products selection screen appears.

  2. If desired, use the Products Filter to narrow the options in the Available Products list.
  3. In the Available Products list, click the appropriate product ManuScripts, and then click OK.
  4. The revised Selected ManuScripts list is displayed.

To delete products from the Selected ManuScripts list:

  1. From the Selected ManuScripts list, select a product ManuScript to delete, and then click the Delete button .
  2. Repeat until all appropriate ManuScripts have been deleted.
  3. Click Next.

    The Map Shared Data Fields screen appears.

  4. Follow the steps below to modify shared data mapping or to exit the wizard without changing the shared data field mapping, and then click Finish.
Step Three: Map Shared Data Fields

This page displays the current shared data mappings for the portfolio.

To change read-only status of shared data:

  1. To the right of the shared data field name, click the check box in the Protected columnto set the field as read-only on quote and policy interview screens, or clear the check box to remove the read-only status.
  2. Repeat for all fields to be changed.
  3. Follow the steps below to edit shared data field mappings, or click Finish to exit the wizard.

To modify the shared data mapping:

  1. For the desired product ManuScript, in the Shared Data field row, click the empty text box in the Ellipsis column .

    The Field Selection dialog box appears.

  2. Select the appropriate ManuScript field or group, and then click OK.
  3. Repeat for all desired fields in the ManuScript, and then repeat steps 1-3 for any other ManuScripts to be updated.
  4. When all changes have been made, click Finish.

Deleting a Portfolio Mapping

The first screen of the Portfolio Mapping Wizard allows users to delete an existing mapping.

To delete a portfolio mapping:

  1. From EXAMPLE Author®, in the Fields View, on the Tools menu, click Portfolio Mapping.

    The Portfolio Mapping Wizard opens.

  2. Click Delete existing mapping, and then select the name of the portfolio mapping to be modified.
  3. Click Delete.
  4. In the Deletion Confirmation box, click Yes to delete the mapping or No to cancel the deletion.
