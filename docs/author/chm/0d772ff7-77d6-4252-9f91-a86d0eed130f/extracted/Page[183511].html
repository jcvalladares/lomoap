Setting Field Paths

Fields View

The Data Path property is the element or attribute of the XML data document where the group is mapped or that contains the value of the field. To change or add a path to a field, the field must be public, and a schema must be defined for the ManuScript.

To set the Data Path property:

  1. Click the field or group.
  2. On the Definition tab, click Path.

    The Path Selector dialog box appears.

  3. Click the item from the pre-determined schema to develop a path.
  4. Click OK.
