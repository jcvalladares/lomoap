Use the Search Viewer to search the entire ManuScript for relevant text.

To search using the Search Viewer:

  1. In the Tools menu, click Search Viewer.

    You can also:
    Press F7.

  2. In the Enter Search Criteria text box, enter the text to find.
  3. (Optional) Select the Match Case check box to search for only items matching the case of the entered text.
  4. Click Search.

    The list includes the Name, Object, and Where text is found for all items matching the search criteria. The object can be a field, group, or form.

  5. Double-click any item in the list to open it in the Fields View or Forms Mapper.
