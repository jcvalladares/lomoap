Designing Version 2 Pages

Save Section to .PDF Save Page to .PDF

When using Page Designer to create version 2 pages, you specify:

  • PageSets
  • Pages
  • Groups
  • Sections and tables
  • Various page widgets, including accordion widgets, comparison widgets, grid widgets, progress bar widgets, and XHTML widgets
  • Fields
  • Actions

The Interview Preview and Documentation Preview are disabled for version 2 pages. The Interview Preview and Documentation Preview tabs may only be used with version 1 pages.
