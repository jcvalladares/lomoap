The order of execution of the value types of a public field is listed below. For each step, if the property is set to (n/a), that step is ignored. Otherwise, the value of the field is modified by the rule. Any access to the field during the execution of these rules returns the in-progress value of the field.

The ManuScript executes field Properties in the following order:

  1. Check the Applicable status of the field. If the Applicable status is false, check only the Default rule.
  2. Execute the fields listed with a Pre-Effect type on the Affects tab.
  3. Access the value from the data document according to the Path of the field.
  4. If the path node does not yet exist in the data document or the value of the node is empty, check the Default rule. If a value is returned in the Default rule, set the value of the field to that default value and issue a message indicating that the default was applied to the field.
  5. Apply the Value rule.
  6. Check the Minimum rule. If there is a specified minimum and the current value of the field is less than the specified minimum, set the value of the field to the specified minimum, and issue the message associated with the minimum rule.
  7. Check the Maximum rule. If there is a specified maximum and the current value of the field is greater than the specified maximum, set the value of the field to the specified maximum, and issue the message associated with the maximum rule.
  8. Apply any Miscellaneous Rules to the value.
  9. If the value was modified, assign the node in the data document, as specified by the Path, the resulting new value. If the node does not yet exist in the data document, add it.
  10. Execute the fields listed with a Post-Effect type on the Affects tab.

For private fields, the order of execution is to access the Value rule, apply Pre-Effect fields, and then apply any Miscellaneous Rules.
