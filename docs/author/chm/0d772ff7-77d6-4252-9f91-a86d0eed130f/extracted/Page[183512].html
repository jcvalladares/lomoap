Setting the Encrypt Data Property

Save Page to .PDF

Fields View

The Encrypt data property encrypts the value of public fields in session data. This encryption is useful in securing sensitive user-entered data.

For the Encrypt data property to work correctly, a valid Encryption.config file must be specified for the EncryptionConfigPath configuration setting in the Server.config file.

To enable encryption on a public field:

  1. Click the public field.
  2. On the Definition tab, select the Encrypt data check box.
