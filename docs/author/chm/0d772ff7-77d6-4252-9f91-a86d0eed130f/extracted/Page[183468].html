Printing ManuScript Reports

Save Page to .PDF

Users may create reports from the EXAMPLE ManuScripts™ XML by using Author's pre-defined report formats or by creating custom reports.

Printing Standard Reports

Users may create and print reports using Author's pre-defined reports. The following report formats are available:

  • Fields List — Lists, by group, the field IDs, captions, and paths for all public fields and the IDs for all private fields.
  • Tables List — Lists and displays all tables in the ManuScript.
  • Calculations List — Lists and displays all calculations in the ManuScript
  • Public Groups and Fields List

To print a standard report:

  1. Click the Print button .

    The Report/Print Options dialog box appears and displays the standard Author reports and any previously defined custom reports.

    You can also:
    • On the File menu, click Print.
    • Press CTRL+P.

  2. In the Select a report list, click the report to print.
  3. Click Preview.

    The Print Preview dialog box appears.

  4. Click Print to print the report, or click Print-to-File to save it.
Printing Custom Reports

Author allows users to create and print custom reports from the EXAMPLE ManuScripts™ XML.

To print a custom report:

  1. Click the Print button .

    The Report/Print Options dialog box appears.

    You can also:
    • Press CTRL+P.
    • On the File menu, click Print.

  2. Click Add.

    The Add Print Report dialog box appears.

  3. Enter a Report Description.

    This description will appear in the list of existing reports.

  4. In the View As list, click the appropriate option:
    • HTML
    • XML
  5. Click the Browse button  to the right of the XSL File Name text box.

    The Select XSL Path/File dialog box appears.

  6. Browse to the file to use, and then click Open.
  7. Click OK.

    The Print Preview dialog box appears. You can click Print to print the report, or save it by clicking Print-to-File.
