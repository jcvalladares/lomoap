Calculation

Save Page to .PDF

With a Calculation value type, you specify an equation to determine the value. Each step of the equation is listed in the calculation grid. Steps are performed in the order listed, modified by groupings. Calculation fields do not follow the standard mathematic order of operations. Be sure to group the lines in your calculation appropriately.

When the value of a field is determined by a calculation, the calculation definition identifies the operators, values, groupings, and rounding used to calculate the value.

Defining a Calculation

Fields View

To define a Calculation value:

  1. In the dropdown list for the appropriate property, click Calculation.
  2. Specify each step in the calculation:
    1. In the Op list, click the operator.

      For a description of operators, see Calculation Operators.

      The first operator in any equation must be =.

    2. Enter the Value.

      You can enter a constant value or click the Ellipsis button  to use the Reference Select dialog box to select a field reference.

    3. (Optional) In the Round list at the end of each line, click the appropriate rounding for the calculation.
  3. (Optional) Highlight steps to be grouped in the calculation, and then click the Group button .
Ignoring a Calculation

Fields View

A ManuScript can include a decision as to whether or not a calculation is performed. The calculation may not be pertinent in some situations, and you may wish to use a value other than the calculation result.

When you select the Ignore calculation when check box, the ManuScript checks a condition before processing the calculation and then determines whether to use the value of the calculation or another value. For example, you only need to compute a premium if a particular coverage is requested.

To limit when a calculation is performed:

  1. Select the Ignore calculation when check box to specify conditions for the calculation.
  2. Click CB to use the Condition Builder dialog box to specify the conditions under which the calculation should be ignored.
  3. In set the value to, enter the value to be used when the calculation is ignored.

    You can enter a constant value or click the Ellipsis button  to use the Reference Select dialog box to select a field reference.

You can use the following rounding options. As a rule, the digits 1, 2, 3, and 4 round down and 5, 6, 7, 8, and 9 round up.

Option

Description

Dollar (1)

Rounds to the nearest whole number.

Rounds to the nearest .0, .5 or 1.00.

Quarter (.25)

Rounds to the nearest .0, .25, .5, .75, or 1.00.

TwentyCents (.20)

Rounds to the nearest .0, .2, .4, .6, .8, or 1.00.

Dime (.10)

Rounds to the nearest tenth.

Nickel (.05)

Rounds to the nearest .00 or .05.

Penny (.01)

Rounds to the nearest hundredth.

3-digits

Rounds to the nearest thousandth.

4-digits

Rounds to the nearest ten-thousandth.

5-digits

Rounds to the nearest hundred-thousandth.

10s

Rounds to the nearest ten.

100s

Rounds to the nearest hundred.

1000s

Rounds to the nearest thousand.

Removes all digits after the decimal without any rounding. Original whole number remains.

Removes all digits after the tenths place without rounding.
