Conversion Support for Custom Parameters

Save Page to .PDF

During conversion to Version 2 pages, the Page Converter supports all custom parameters defined in Version 1 pages by:

  • Converting any custom parameters supported by Version 2 pages to the equivalent advanced properties
  • Adding any custom parameters not supported by Version 2 pages (that is, any parameters that do not have equivalent advanced properties) as Custom Properties. Custom properties appear below all other properties.

    When a custom parameter from a version 1 page is added as a custom property to a version 2 page during conversion, you should evaluate whether any of the standard properties for version 2 pages already accomplish what is specified in the custom property. If the standard properties do not accomplish what is needed, you must customize your skin to accommodate the custom property.
