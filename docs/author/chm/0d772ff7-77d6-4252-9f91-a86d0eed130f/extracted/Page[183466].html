Importing ManuScripts

Save Page to .PDF

You can import all or part of an existing ManuScript. When you import ManuScript elements into another ManuScript, copies of those elements become part of the new ManuScript with no connection to the original ManuScript. For more information, see Importing Fields and Groups.

Importing an entire ManuScript makes a copy of the ManuScript and places it in the ManuScript Catalog directory. To include the ManuScript in the Catalog but not copy it to the ManuScript Catalog directory, link the ManuScript into the Catalog, rather than importing it.

Importing a ManuScript into the Catalog

Importing a ManuScript into the Catalog creates a copy of the ManuScript and stores that copy in the system location dictated by the Catalog path and the key values specified in the ManuScript.

To import a ManuScript into the Catalog:

  1. Click the Open ManuScript button .

    The ManuScript Catalog dialog box appears.

  2. Click the Import button .

    The Import ManuScript dialog box appears.

  3. Browse to the appropriate location, and then click the file to import.
  4. Click Open.

    The ManuScript Catalog Detail dialog box appears.

  5. (Optional) Change the Description for the new ManuScript.
  6. (Optional) Change the key Values as appropriate.
  7. Click OK.

The lob and state keys are used to create a directory structure in the Catalog location. The ManuScript or data file is stored in the state folder which is stored within the lob folder in the path set up for the Catalog. The keys used previously in the ManuScript are the default when you import a ManuScript into the Catalog.

Importing Elements into an Existing ManuScript

To import elements into an existing ManuScript:

  1. On the File menu, click Import.

    The Import Wizard dialog box appears.

  2. Click Catalog.

    The ManuScript Catalog dialog box appears.

  3. Click the ManuScript from which to import, and then click Load.
  4. Click the appropriate import option.

    The options are:

    • Import Fields/Groups
    • Import Tables
    • Import Pages
    • Import Forms

    You can select only one element type during an import function. If you need to import additional types, you must do a second import.

  5. Click Next.

    The elements in the selected ManuScript are displayed in the Select the items to import list.

  6. Click each element to import.

    You can multi-select by using CTRL+click and SHIFT+click.
    If you select:

    • A group, you automatically select all fields and groups contained within the selected group.
    • A page, you automatically select all elements within the page.
  7. Click Next.

    The elements of the ManuScript are listed. Any items that already exist in the current ManuScript are automatically deselected. You can clear or force the importation of any element by selecting or clearing the appropriate check box.

  8. Click Finish.

    All selected items are imported into the ManuScript.

If you start with a new ManuScript with just the root element and import all elements from another ManuScript, you are, in essence, importing the ManuScript into the Catalog. A better method is to import the ManuScript directly.

Import ManuScript dialog box

In the Import ManuScript dialog, browse to and then click an appropriate file, and then click Open.
