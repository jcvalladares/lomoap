The ManuScript Catalog

Save Page to .PDF

The ManuScript Catalog is an XML file that contains pointers and other attributes that specify the system location of ManuScript files. These files may be:

  • Created directly
  • Linked into the Catalog
  • Imported into the Catalog

To open the ManuScript Catalog:

  • Click the Open ManuScript button .

    The ManuScript Catalog dialog box appears.

    You can also:
    • On the File menu, click Open.
    • In the Open/New ManuScript dialog box, click Open Existing.

From this point, you can perform a variety of tasks including:

  • Opening a ManuScript
  • Linking a ManuScript into the Catalog
  • Importing a ManuScript into the Catalog
  • Exporting a ManuScript
  • Removing a ManuScript from the Catalog

Catalog Keys

The default and required Catalog keys are lob (line of business) and state. For organizational purposes, you can further subdivide ManuScripts or data files by adding additional keys. You do this in the Catalog dialog box. You can also remove keys you have added.

Adding Catalog Keys

Catalog keys help to organize your files. The default keys are lob (Line of Business) and state.

To add a catalog key:

  1. In the Catalog dialog box, click Add Key.

    The New Key Name dialog box appears.

  2. Enter the new key name, and then click OK.
Deleting Catalog Keys

The default keys, lob (line of business) and state cannot be removed, but additional keys you have created can be deleted.

To delete a Catalog key:

  1. In the Catalog dialog box, click the key to delete.
  2. Click Delete Key.

    The Confirm dialog box appears.

  3. Click Yes to delete the key, or No to cancel.
Filtering the Catalog

Keys are useful for filtering a Catalog to display only applicable items.

To filter a Catalog:

  • For each Key Name, click the appropriate Restriction in the dropdown list.

    The list of items now shows only those files that match the key value you chose. You can filter by any combination of key values.

Opening and Closing ManuScripts

To open a ManuScript:

  1. Click the Open ManuScript button .

    The ManuScript Catalog dialog box appears.

    You can also:
    • On the File menu, click Open.
    • In the Open/New ManuScript dialog box, click Open Existing.

  2. Click a ManuScript in the list, and then click Load.

    The selected ManuScript opens.

To close a ManuScript and the EXAMPLE Author® program:

  • On the File menu, click Exit.

    You can also:
    Click the Close button  in the upper-right corner of the window.

    If you have not saved the ManuScript since making a change, EXAMPLE Author® will prompt you to save the changes.

Creating New ManuScripts

To create a new ManuScript:

  1. Click the New ManuScript button .

    The Open/New ManuScript dialog box appears.

    You can also:
    On the File menu, click New.

  2. Click Blank ManuScript.

    The Add New Group dialog box appears.

  3. Enter a name for the root group of the new ManuScript, and then click OK.

    It is best practice to use the name data for the root group of any ManuScript. This group must be public.

Saving a ManuScript for the First Time

When saving a new ManuScript for the first time, you must first enter a Description and key Values.

To save a ManuScript:

  1. Click the Save ManuScript button .

    The ManuScript Catalog Detail dialog box appears.

    You can also:
    On the File menu, click Save.

  2. Enter a Description.
  3. For each Key Name, click an appropriate Value.

    You may add Values to Key Names by clicking Add on the appropriate line.

  4. Click OK.

If you have previously saved a ManuScript, saving again will not open the ManuScript Catalog Detail dialog box.

Linking a ManuScript

A link to a ManuScript or data file is similar to a shortcut button on your desktop. Selecting that link opens the ManuScript or data file from its original location. To have a copy of the ManuScript or Data File reside in the ManuScript or Data File Catalog directory, you import the item.

To link a ManuScript or data file into the Catalog:

  1. In the ManuScript Catalog dialog box, click the Link button .

    The Link ManuScript dialog box appears.

  2. Browse to the appropriate directory, and then click the ManuScript.
  3. Click Open.
  4. (Optional) Change the Description as appropriate.
  5. (Optional) Change the key Values as appropriate.
  6. Click OK.

The lob and state keys are used to create a directory structure in the Catalog location. The ManuScript or data file is stored in the state folder which is stored within the lob folder in the path set up for the Catalog. The keys used in the ManuScript or data file remain the default when you link the item into the Catalog.

Removing ManuScripts

Removing a ManuScript from the Catalog has one of two results. If the ManuScript is:

  • Linked into the Catalog, you remove only the link to the ManuScript.
  • An imported ManuScript, or one that was created in the Catalog structure, you delete the ManuScript from the Catalog and delete the file from the folder on the computer.

To determine if the ManuScript is linked or imported, check the Source by clicking Advanced in the ManuScript Catalog Detail dialog box. If the ManuScript is not stored in the Catalog path, it is a linked ManuScript.

To remove a ManuScript:

  1. In the ManuScript Catalog dialog box, click the ManuScript you wish to remove.
  2. Click the Remove button .

    The Confirm dialog box appears.

  3. Click Yes to remove the ManuScript or No to cancel.

Duplicating ManuScripts

You can copy a ManuScript without linking the copy to the original ManuScript.

To duplicate a ManuScript:

  1. In the ManuScript Catalog dialog box, click the appropriate ManuScript.
  2. Click the Duplicate button .

    The ManuScript Catalog Detail dialog box appears.

  3. (Optional) Change the Description for the duplicated ManuScript.
  4. (Optional) Change the key Values as appropriate.
  5. Click OK.

Changing ManuScript Details

The ManuScript details are stored in the ManuScript XML. The Description appears on the title bar of the EXAMPLE Author® application, and the key Values determine where the ManuScript is saved.

To change the ManuScript Description:

  1. In the ManuScript Catalog dialog box, click the ManuScript.
  2. Click the Properties button .

    The ManuScript Catalog Detail dialog box appears.

  3. Enter an appropriate Description.

    The description may contain spaces and any alphanumeric characters.

  4. Click OK.

To change ManuScript key Values:

  1. In the ManuScript Catalog dialog box, click the ManuScript.
  2. Click the Properties button .

    The ManuScript Catalog Detail dialog box appears.

  3. For each Key Name, click an appropriate Value.

    You can add key Values by clicking Add on the appropriate line.

Creating a New ManuScript Version

You can create a new version of a ManuScript with the same content. The new ManuScript has the same ManuScript ID as the item on which it was based, but has a new Version ID and file name. The internal version number of the ManuScript is incremented. The Catalog opens a Date Selector dialog box to allow a new date to be set for the version. By default, the new entry retains the same description and keys.

When there are multiple versions of a ManuScript, EXAMPLE Author® facilitates easy transition from version to version while editing. When a ManuScript is loaded into EXAMPLE Author®, all the entries in the Catalog that have the same ManuScript ID as the loaded ManuScript are listed in the Versions list at the top of the main screen. Selecting any one of these entries from the Versions list automatically loads the selected version of the ManuScript.

To create a new version from the ManuScript Catalog:

  1. In the ManuScript Catalog dialog box, click the appropriate ManuScript.
  2. Click the New Version button .

    The Date Selector dialog box appears.

  3. Click the appropriate date.

    This is the date the new version of the ManuScript becomes active.

  4. Click OK.

    You can view the new version number and date in the ManuScript Properties or ManuScript Catalog Detail dialog boxes.

Exporting ManuScripts

You export a ManuScript to copy the file from the Catalog directory to another directory of your choice.

To export a ManuScript:

  1. In the ManuScript Catalog dialog box, click the ManuScript.
  2. Click the Export button .

    The Export ManuScript dialog box appears.

  3. Click the appropriate directory.
  4. In the File name text box, enter a name for the file.
  5. Click OK.

Viewing ManuScript Sources

In the ManuScript Catalog Detail dialog box, you can see where a ManuScript is stored.

To view the file source:

  1. In the ManuScript Catalog dialog box, click the file.
  2. Click the Properties button .

    The ManuScript Catalog Detail dialog box appears. It includes the description of the file and the keys assigned to it.

  3. Click Advanced.

    The dialog box expands to show additional information. The directory of the selected ManuScript is listed in the Source text box.

Viewing Dependencies

When a ManuScript is derived from another ManuScript, it is dependent upon the base ManuScript. To see how various ManuScripts are related in terms of inheritance, you can view the dependencies a ManuScript has to others.

To view dependencies:

  • In the ManuScript Catalog dialog box, click the appropriate ManuScript, and then click the Dependencies button .

    The ManuScript Dependencies dialog box appears. This dialog box shows the ManuScripts that the selected ManuScript inherits in the Used With list and the ManuScripts that inherit the selected ManuScript in the Used By list.
