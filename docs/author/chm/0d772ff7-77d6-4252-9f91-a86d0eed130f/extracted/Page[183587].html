Automatic Update

Save Page to .PDF

Automatic Update option saves changes automatically, rather than asking for confirmation of each change.

To use the Automatic Update feature:

  • Click the Automatic Update button .

    You can also:
    On the Tools menu, click Automatic Update.

    The feature is turned on when the button appears highlighted.

    EXAMPLE Author® remembers your Automatic Update settings upon exiting the application. For example, if you enable the feature, exit the application, and then open the application at a later time, the Automatic Update feature will still be enabled.
