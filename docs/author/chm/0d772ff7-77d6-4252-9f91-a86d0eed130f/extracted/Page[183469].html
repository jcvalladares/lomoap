Deploying a ManuScript

Save Page to .PDF

You use the Deployment Manager dialog to deploy a ManuScript to one or more servers at the same time. Deployment readies the ManuScript for use by a downstream Web display system.

To deploy a ManuScript:

  1. On the File menu, click Deploy ManuScript.

    The Deployment Manager dialog box appears.

  2. Select the Deploy check box for each EXAMPLE Server® to receive the ManuScript.
  3. If needed, enter the User Name and Password on the appropriate lines.
  4. In the Upon success set status of ManuScript to list, click the appropriate status.

    The options are:

    • Deployed
    • Approved
    • Passed
    • QA
    • Development
    • Exclusive
    • Suspended
  5. (Optional) Select the Include Dependencies check box to include all dependencies of the ManuScript.
  6. Click Deploy.

    After deployment, you can view the XML response from the EXAMPLE Server® in the text box.
