Forms Mapper Controls

Save Page to .PDF

You control the Forms Mapper view using buttons, menus, and keyboard shortcuts.

Forms Mapper Edit Menu

The Forms Mapper Edit menu includes the following options.

Menu Option

Action

Undo (CTRL+Z)

Undo the last action performed.

Manage Print Jobs

Open the Manage Print Jobs dialog box.

Edit Control File Field List

Edit the control file to specify the order and location of forms to be printed.

Form

Manage forms. For more information, see Form Submenu.

Sub-Form

Manage sub-forms. For more information, see Sub-Form Submenu.

Merge Field

Manage merge fields. For more information, see Merge Field Submenu.

Group

Manage groups. For more information, see Group Submenu.

Generate Forms Schema

Generate a data schema that document providers can use to map forms data.

Export to CSV

Generate a sample .csv file for the selected document. The .csv file can be used with Microsoft Word to generate documents that are used by Forms Mapper. For more information, see Using a .Csv File in the EXAMPLE Forms™ Reference Guide.

Refresh List

Refresh the list of forms.

Find (CTRL+F)

Opens the Search dialog box to enter text to find.

Find Next (F3)

Finds the next occurrence of the previously entered text.

View Form XML

Open the XML Viewer dialog box to see the XML for the selected form.
Form Submenu

The Form submenu includes the following options.

Menu Option

Action

Add Form (CTRL+A)

Add a new form to the list of forms.

Delete Form (CTRL+D)

Remove the selected form from the list of forms.

Rename Form

Rename the selected form.

Duplicate Form

Duplicate the selected form and its sub-forms. You are prompted to rename the duplicate form.

Form Properties

Define properties for the selected form.

Add Multiple Documents

Select multiple files and insert them as forms.

Move Form Down (CTRL+ALT+W)

Move the selected form down in the list.

Move Form Up (CTRL+ALT+U)

Move the selected form up in the list.

The Sub-Form submenu includes the following options.

Menu Option

Action

Edit Sub-Form

Merge Field Submenu

The Merge Field submenu includes the following options.

Menu Option

Action

Add Merge Field (CTRL+M)

Adds a merge field.

Remove Merge Field (CTRL+R)

Removes the selected merge field.

Duplicate Merge Field (CTRL+ALT+C)

Duplicates the selected merge field.

Move Merge Field Down (CTRL+W)

Moves the selected merge field down in the list.

Move Merge Field Up (CTRL+U)

Moves the selected merge field up in the list.

Refresh Merge Fields

Searches all the forms in Forms Mapper and add any new merge fields to the list for each form.

Forms Mapper Shortcut Menu

When you right-click the Forms list in Forms Mapper, a menu appears with the following options.

Menu Option

Action

Add Form (CTRL+A)

Adds a new form to the list of forms.

Delete Form (CTRL+D)

Removes the selected form from the list of forms.

Demote/Revert Form

Reverts the form to its former inherited state.

 

Rename Form

Renames the selected form.

 

Duplicate Form

Duplicates the selected form and its sub-forms

 

Form Properties

Opens the Form Properties dialog box to define properties for the selected form.

Add Sub-Form(s) (CTRL+ALT+A)

Adds a new sub-form to the list of forms.

 

Edit Sub-Form

Edits the selected sub-form.

 

Reset Sub-Form Path

Resets the data path for the sub-form.

Delete Sub-Form (CTRL+ALT+D)

Removes the selected sub-form from the list of forms.

Move Sub-Form Right (CTRL+ALT+R)

Moves the selected sub-form right. (Demote)

Move Sub-Form Left (CTRL+ALT+L)

Moves the selected sub-form left. (Promote)

Move Form/Sub-Form Up (CTRL+ALT+U)

Moves the selected form or sub-form up in the list.

Move Form/Sub-Form Down (CTRL+ALT+W)

Moves the selected form or sub-form down in the list.

Refresh List

Refreshes the Forms list.

 

Find (CTRL+F)

Opens the Search dialog box to enter text to find.

 

Find Next (F3)

Finds the next occurrence of the previously entered text.

 

View Form XML

Views the XML for the selected form.

 

View Inheritance (Forms)

Opens the Inheritance dialog box to view the current ManuScript's forms inheritance chain.
