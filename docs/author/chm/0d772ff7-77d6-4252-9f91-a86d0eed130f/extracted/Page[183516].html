Setting the Applicable Property

Save Page to .PDF

Fields View

The Applicable property specifies the conditions under which the field is to be displayed or executed.

To set the value of the Applicable property:

  1. Click the field.
  2. On the Definition tab, in the Applicable list, click the appropriate value type.

    For more information, see Defining Property Value Types.

  3. Complete the Definition pane for the value type.
