Grid Widgets

Save Section to .PDF Save Page to .PDF

Grid widgets display iterative fields and actions within a sortable grid control. Like tables, grid widgets can display iterative fields and actions in a table. Unlike tables, however, grid widgets allow users to sort and rearrange table columns. In addition, grid widgets can paginate, displaying on each page the number of iterations specified in the Maximum Iterations property specified for the associated group.

Grid widgets always display in the following manner:

  • Fields are laid out across the page in columns; iterations are laid out down the page in rows (Layout Direction: Across).
  • Field captions display only for the first iteration (Field Caption Display: First Iteration).
  • Field captions display above field values (Field Caption Position: Above Field).
  • Grid widget content is read-only (Read-Only Content: True).

You can add, duplicate, and remove grid widgets, as well as define grid widget properties and convert grid widgets to sections or tables. Grid widgets can be nested within sections or tables.

Duck Creek Technologies, Inc. does not support: 
• Editable radio buttons in grids (editable boolean fields with a format mask of radio or radio:1)
• Multiple grids per page
• Sorting of paging grids

Adding a Grid Widget

 Page Designer View

You can add grid widgets by:

  • Adding the grid widget under a section or table
  • Converting the section automatically created under the page group
  • Adding a group and converting the corresponding table to a grid widget

    When adding grid widgets, remember that a grid widget iterates through the closest parent group in the tree (that is, the group immediately above the grid widget in the hierarchy).

To add a grid widget under a section or table:

  1. Click the section or table under which to add a grid widget.
  2. On the Edit menu, click Advanced, and then click Add Grid Widget.

    You can also:
    •Press CTRL+ALT+G.
    •Right-click a section or table, click Advanced, and then click Add Grid Widget.

To convert the section automatically created under the page group:

  1. Click the section beneath the page group.
  2. On the Edit menu, click Convert To Grid Widget.

    The selected section appears as a grid widget in the Page Designer list.

    You can also:
    Right-click the section, and then click Convert To Grid Widget.

To add a group and convert the corresponding table:

  1. Click the section or table under which to add the group.
  2. Click the Add Group button .

    The Select Group Association dialog box appears.

    You can also:
    Press CTRL+G.

  3. Click the appropriate group, and then click OK.

    The system adds the group and a corresponding table.

  4. Click the table beneath the group.
  5. On the Edit menu, click Convert To Grid Widget.

    The selected table appears as a grid widget in the Page Designer list.

    You can also:
    Right-click the table, and then click Convert To Grid Widget.

Duplicating a Grid Widget

 Page Designer View

To duplicate a grid widget:

  1. Click the grid widget you wish to duplicate.
  2. On the Edit menu, click Duplicate.

    You can also:
    Right-click the grid widget, and then click Duplicate.

    The Duplicate Grid dialog box appears.

  3. Click the type of action to take. Options are:
    • Duplicate grid structure only
    • Duplicate grid structure and fields
    • Duplicate grid structure and replace fields
  4. If you choose to duplicate the grid widget structure and replace fields, define Field Replacement Rules.
    1. Click a group for Replace fields from the group.
    2. Click a group for With similar field in the group.
  5. Click OK.

Deleting a Grid Widget

 Page Designer View

To delete a grid widget:

  1. Select the grid widget you wish to delete.
  2. Click the Delete button .
  3. In the Confirm dialog box, click Yes to confirm the deletion, or No to cancel.

Defining Grid Widget Properties

 Page Designer View

To define a grid widget, specify the following properties.

Property

Description

General

Name

Name of the grid widget.

Display

Grid Caption

Text to describe the grid widget.

Header Caption

This property is not available for use with grid widgets.
Read-Only Content

Specification of whether grid widget content should be read-only.

Show Condition

Specification of when to display the grid widget.
Sorting

Indication of whether the grid widget is sortable.

Duck Creek Technologies, Inc. does not support sorting of paging grids.

Grid Caption Style

CSS styles to apply to the grid widget caption. Styles apply according to CSS inheritance rules.

Grid Style

CSS styles to apply to the grid widget content. Styles apply according to CSS inheritance rules.

In addition to defining the above properties, you can also define annotations for grid widgets, and you can add actions to grid widgets. Grid widget actions appear as links in the grid widget under an unnamed column. For information on adding actions, see Actions.

Setting the Name Property

 Page Designer View

The Name property contains the name of the grid widget. This name appears on the grid widget in the Page Designer list.

To set the value of the Name property:

  1. In Page Designer, click the grid widget.
  2. On the Definition tab, click Name.
  3. Enter the grid widget name.
Setting the Grid Caption Property

 Page Designer View

The Grid Caption property contains the text to display as the title of the grid.

To set the value of the Grid Caption property:

  1. In Page Designer, click the grid widget.
  2. On the Definition tab, click Grid Caption.
  3. Enter the grid widget caption.
Setting the Header Caption Property

 Page Designer View

This property is not available for use with grid widgets.

Setting the Read-Only Content Property

 Page Designer View

The Read-Only Content property specifies whether the grid content is read-only.

To set the value of the Read-Only Content property:

  1. Click the grid widget.
  2. On the Definition tab, click Read-Only Content.
  3. In the Read-Only Content list, click False or True.
Setting the Show Condition Property

 Page Designer View

The Show Condition property specifies when to show the grid widget.

To set the value of the Show Condition property:

  1. Click the grid widget.
  2. On the Definition tab, click Show Condition.
  3. To the right of the Show Condition text box, click the Ellipsis button  to use the Reference Select dialog box to select a boolean field.
Setting the Sorting Property

 Page Designer View

The Sorting property specifies whether the grid widget is sortable by column.

Duck Creek Technologies, Inc. does not support sorting of paging grids.

To set the value of the Sorting property:

  1. Click the grid widget.
  2. On the Definition tab, click Sorting.
  3. In the Sorting list, click True or False.
Setting the Grid Caption Style Property

 Page Designer View

The Grid Caption Style property specifies the CSS styles to apply to the grid widget caption. Styles specified in this property will override any global CSS styles assigned. Styles apply according to CSS inheritance rules.

To set the value of the Grid Caption Style property:

  1. Click the grid widget.
  2. On the Definition tab, click Grid Caption Style.
  3. To the right of the Grid Caption Style text box, click the CSS button  to use the CSS Selector dialog box to select the desired styles.
Setting the Grid Style Property

 Page Designer View

The Grid Style property specifies the CSS styles to apply to the grid widget content. Styles specified in this property will override any global CSS styles assigned. Styles apply according to CSS inheritance rules.

To set the value of the Grid Style property:

  1. Click the grid widget.
  2. On the Definition tab, click Grid Style.
  3. To the right of the Grid Style text box, click the CSS button  to use the CSS Selector dialog box to select the desired styles.
