Setting Field Data Types

Save Page to .PDF

 Fields View

To set the value of the Data Type property:

  1. Click the field.
  2. On the Value tab, in the Data Type list, click the appropriate data type. Fields and tables can hold or return the following data types.

    Type

    Description

    boolean

    True or false (1 or 0) value. Any number other than 1 returns a 1, and any string other than True or False yields an error.

    date

    Date in a YYYY-MM-DD format.

    datetime

    Date and time in a YYYY-MM-DD hh:mm:ss format.

    float

    Floating point number. May be as low as 5.0 x 10^-324 and as high as 1.7 x 10^308 and may have 15 to16 significant digits.

    int

    Integer. Whole number that may be as low as -2147483648 and as high as 2147483647 and may have 10 significant digits.

    string

    Character value.

    time

    Time in a hh:mm:ss format.
