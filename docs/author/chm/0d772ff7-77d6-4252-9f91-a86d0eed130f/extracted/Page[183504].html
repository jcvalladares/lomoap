Setting Field Defaults

Save Page to .PDF

Fields View

The Default property contains the default value for the field.

To set the value of the Default property:

  1. Click the field.
  2. On the Value tab, in the Default list, click the appropriate value type.

    The Default is most often defined as a Constant/Field value type.

    For more information, see Defining Property Value Types.

  3. Complete the Definition pane for the value type.

    Define the default.

If a field has an Option list, you may also set the Default value for the field by clicking the desired option and then clicking Set Default.
